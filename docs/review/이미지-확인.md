# 이미지 확인 — 사람이 눈으로 봤다

**이미지는 실명 검사(check_names)가 못 봅니다** — 글이 아니라서요. 그래서
docs/ 의 이미지는 사람이 눈으로 보고 실명이 없음을 확인한 뒤 **경로와 내용
해시를 여기에 적어야** 통과합니다. 11-2 의 「볼 목록이 불완전하다」 를
이미지까지 넓힌 것입니다 — 2026-09-07 에 개발 DB 의 익명화 이전 자료로 찍은
스크린샷 2장이 실명을 담은 채 커밋 직전까지 갔습니다(검토자가 막음).

**해시(md5 앞 12자리)도 함께 적습니다.** 경로만 적으면 같은 이름으로 다시
찍은 것(재촬영)이 조용히 지나갑니다 — 내용이 바뀌면 해시가 갈려 다시
사람 확인을 요구합니다. 해시는
`python -c "import hashlib,sys;print(hashlib.md5(open(sys.argv[1],'rb').read()).hexdigest()[:12])" <파일>`
로 잽니다.

**보는 것은 실명만이 아닙니다.** 11-2 의 「회의록·제안·논의의 줄을 옮겨
적지 않는다」 는 **찍은 화면에도 걸립니다** — 회의록 화면을 찍으면 그
본문이 그림 안에 그대로 실립니다. 확인할 때 둘을 봅니다:

1. **실명·실제 장소·실제 연락처가 없는가**
2. **회의록·논의 본문이 보이지 않는가** — 보이면 본문을 지우거나 예시
   문장으로 바꿔 다시 찍습니다

**이 검사는 1번도 2번도 기계가 못 봅니다** — 그림 안의 글자를 못 읽기
때문입니다. 기계가 보는 것은 「사람이 봤다는 기록이 있는가」(경로·해시)
뿐입니다. 그래서 아래 한 줄이 **사람이 무엇을 봤는지**를 말해야 합니다.

한 줄에 하나 — `경로 | 해시 | 언제 · 누가 · 무엇을 확인했나`.
