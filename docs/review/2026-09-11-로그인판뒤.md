## 1-2. 운영 자료를 바꾸는 명령은 누가 돌리나 (11-2 — **여기가 정본**)

**사람이 직접 해야 하는 것은 둘뿐입니다.**

| 사람이 한다 | 왜 |

| 되돌릴 수 없는데 미리 재어 본 적이 없는 것 — 사본 없이 지우는 것, 바깥으로 나가는 것(메일·문자·결제) | 미리보기가 없으면 무엇을 잃는지 아무도 모르고, 나간 것은 되돌릴 자리가 없습니다 |

**미리보기 갈림이 아예 없는 도구도 있습니다** — 검토가 갈래 ③ 을 짚었습니다
(세고 곧바로 끊는 한 번짜리라 `--실행` 이 없습니다). 그때는 **세는 것이 곧
미리보기**입니다: 먼저 세어 싣고, 0 이면 거기서 끝내고, 0 이 아닐 때만 돌린 뒤
다시 셉니다. 순서의 뜻은 같습니다 — **무엇이 달라질지 모르는 채로 돌리지

# 6. 돌고 있는 서버에서 확인한 것

**재시작했습니다 — 이번 커밋에 `app/domain/auth.py` 가 들어 있으므로


모릅니다」.

**올라온 뒤 실제로 받아 봤습니다** — 이번 판이 고친 것은 `auth.py` 에서
함수 하나를 걷은 것이라, **걷고도 문이 그대로 도는지**가 볼 것입니다.

| 물은 것 | 답 |
|---|---|
| `GET /login` | 200 · 아이디 칸 있음 |
| `GET /invite/<토큰>` | **303 → `/login`** (걷힌 함수를 쓰던 자리라 여기가 죽었으면 바로 드러납니다) |
| `POST /login` 없는 아이디 | 401 · 「아이디 또는 비밀번호가 맞지 않습니다」 |

> **처음에는 이 장이 없었습니다.** PID 를 사람칸에만 적고 본문에는 안
> 적었는데, 사람칸은 「이유는 적지 않고 어디에 적혀 있는지만 가리킨다」 는
> 자리입니다(11-3 4단계) — **값이 사람칸에만 있고 가리킨 곳이 비어**
> 있었습니다. 검토가 짚었습니다.
