# 제안 2판 — 문장으로 읽은 것 (아직 안 냈습니다)

**이 파일은 스크립트가 덮어씁니다.** 지금은 비어 있습니다 — Claude API 키가
아직 서버에 없어서 표본을 낼 수 없었습니다.

## 왜 지금 비어 있나

낱말 겹침의 성적은 사람이 채웠습니다 — 20개 중 14개(70%),
`docs/review/제안-성적표.md`. 2판을 견주려면 **같은 네 회의**로 다시 내야
하는데, 그러려면 실제로 API 를 불러야 합니다.

**낱말로 물러선 결과를 2판이라고 적지 않습니다.** 그러면 견주는 두 숫자가
같은 방식의 것이 되어 아무것도 재지 못합니다. 그래서 스크립트가 키가 없으면
**아무것도 쓰지 않고 멈춥니다.**

## 채우는 법

1. `docs/배포-안내.md` **14장** 대로 키를 넣습니다 (`data/anthropic_key.txt`)
2. 아래를 돌립니다

   ```
   .venv\Scripts\python.exe scripts/suggest_sample.py ^
       --retreat "2026 여름수련회 Belong"
   ```

3. 이 파일이 **표본 네 회의의 제안과 근거**로 덮어써집니다
4. 표의 `판정`·`X 이유` 칸과 회의마다 있는
   **"마땅히 나왔어야 하는데 안 나온 것이 있나요?"** 를 채웁니다

## 무엇이 들어갈 예정인가

- 회의마다 — 보낸 업무 목록 크기 · 부른 횟수 · **그 회의에 든 값(원)**
- 제안마다 — 종류(결정사항 / 논의 / 새 업무) · 하려는 일 · **근거 또는 인용**
- 사람 평가로 보이는 대목이 있는 회의록이면 그 사실 (제안에는 안 담김)
- 맨 끝에 1판과 견주는 표 (낸 것 · 맞은 것 · 비율 · **놓친 회의**)

## 견줄 때 지킬 것

- **비율로 견줍니다.** 제안 수가 달라지므로 개수로는 견줄 수 없습니다
- **놓친 것을 함께 셉니다.** 안 세면 적게 내는 쪽으로 점수를 올릴 수 있습니다
- **근거도 봅니다.** 맞혔는데 근거가 낱말 하나면 나아진 것이 아닙니다 (6-3).
  2판의 근거는 **문장**이어야 합니다
- **표본을 바꾸지 않습니다.** `26.03.29 (1차)` · `26.05.24` · `26.07.05` ·
  `26.08.09` 넷 그대로입니다
