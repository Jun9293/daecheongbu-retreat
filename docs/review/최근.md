# 1. 목록에 기대지 않는 둘째 축 — `scripts/check_named.py`

**옛말 검사는 사람이 적어야 돕니다.** 적는 것을 잊으면 도구가 없는 것과

그래서 **문서가 이름한 것이 실재하는가**를 봅니다. CLAUDE.md 가 백틱으로
적은 코드 모양을 셋으로 갈라 각각 다른 곳에서 찾습니다.

| 축 | 어디서 찾나 |
|---|---|
| 경로 | `git ls-files` — **`/` 경계에서 끝나면 있는 것**(앞머리를 세어 두지 않는다) |
| 식별자 | **코드 파일만** (자기 자신은 뺀다) |
| 선택자 | CSS·JS·템플릿 |
| 토큰 | `--fz` 같은 것. CSS 토큰과 명령줄 스위치는 생김새가 같아 **나누지 않고** 어딘가 있으면 된 것으로 본다 |

**식별자를 코드에서만 찾는 것이 이 도구의 급소입니다.** 문서까지 뒤지면
다른 문서가 그 이름을 한 번 적어 둔 것만으로 「있다」 가 되어, **잡으려던
바로 그것을 못 잡습니다** — 실제로 지워진 이름 하나가 옛말 목록에 적혀
있다는 이유로 통과했습니다. 처음 판이 그랬고 고쳤습니다.

산문·색값·URL 은 뺐습니다 — 백틱은 강조에도 쓰여서(`지연`·`대기`) 전부
보면 넘김 목록만 늘다가 아무도 안 읽습니다(4-11 과 옛말.md 의 그 판단).
**8장의 모델 표기(캠멜)는 코드블록 안에 있어 이미 빠집니다** — 캠멜을
따로 거르면 `originOf`·`statMenu` 같은 본문의 진짜 함수가 함께 빠지고,
캠멜로 적힌 것은 스네이크로 바꿔 한 번 더 봅니다.

넘기는 것은 `docs/이름-넘김.txt` 에 **왜 넘기는지와 함께** — 저장소 밖
파일 · 지운 화면 · 값이 아니라 모양인 것 · 우리 것이 아닌 이름(`--help` ·
노션 속성). **개수는 적지 않습니다**(10장 — 세어 두면 늘 때마다 어긋납니다).

두 축이 무엇을 잡는지는 11-3 3단계 표에 적었습니다. **이름은 그대로인데
뜻만 바뀐 것은 새 축이 못 보고, 목록에 안 적힌 이름 변경은 옛말 검사가
못 봅니다 — 그래서 둘 다 돌립니다.**
