# 0. 먼저 센 것

네 표 전부 **실제로 돌리거나 코드를 훑어 나온 수**입니다. 재는 법을

## (a) 자가시험이 지나는 길과 안 지나는 길 — 화면별·계정별

재는 법 — 세 화면 × 두 계정에서 자가시험을 돌리고 갈래마다 나온 값을
그대로 옮겼습니다(여섯 판). `· 못 심음` 은 안 지난 것입니다.

> **`· 권한` · `· 자료` · `· 찾는 법` 은 출력이 아니라 제가 읽어서
> 가른 것입니다.** 코드가 내는 못심음 문구는 둘뿐이고(화면 전용인가 ·
> 그 자리가 없는가), 권한이든 자료든 같은 한 문장으로 나옵니다.
> 검토가 짚었습니다 — 표 위에 「나온 값을 그대로 옮겼다」 고 적어 두고
> 한 칸만 사람이 읽은 것이면 그 한 칸을 기계가 낸 것으로 읽습니다.
> `· 화면` 과 `· 건너뜀 잡음` 은 출력 그대로입니다.

> 짚었고, 목록의 빈 칸 탐침은 **제목 줄 오른쪽 한 점만** 봅니다 —
> 자료를 넣어도 안 재집니다. **그 뜻이 작지 않습니다**: ⑤ 를 못 심는다는
> 것은 「빈 영역 클릭으로는 닫힌다」 와 드래그 여섯이 **목록에서 두 계정
> 모두 한 번도 안 지났다**는 뜻입니다. 고치면 열두 판을 다시 돌려야 해서
> 이 판에서는 안 했고 `docs/봐둘것.md` **AK-d** 로 남겼습니다.

# 10. 「확인했습니다」 가 사실인지 스스로 본 것

지난 판에 이 자리에서 **두 번 고쳐 썼습니다** — 개발 서버를 껐다고
적었는데 자식 워커가 포트를 쥐고 답하고 있었고, 주석 하나가 시험이
하는 일과 달랐습니다. 그래서 이번에는 **무엇으로 확인했는지**를 함께
적습니다.

| 적은 것 | 무엇으로 확인했나 |
|---|---|
| 임시 사본을 지웠다 | `git status --short` 에 안 나오는 것 |
| 개발 서버를 껐다 | **8001 이 연결을 거절하는 것**(요청을 보내 확인 — 프로세스를 끝냈는데 답이 오면 살아 있는 것입니다) |
| 운영 서버가 살아 있다 | PID 와 응답 코드를 받아서 |
| 열두 판이 지금 파일로 돌았다 | 판마다 **받은 길이**를 찍어 견줘서 |
| 자가시험이 세 화면 두 계정에서 돌았다 | 여섯 판의 출력을 그대로 실어서 |
| 열두 판 뒤에 바꾼 것이 주석뿐이다 | **한 판 더 돌려서** — 길이가 같아 길이 확인으로는 안 갈립니다 (8-c) |
| 목록 ⑤ 가 찾는 법 때문이다 | 그 자리의 코드를 읽어서 — 한 점만 봅니다 (AK-d) |
| 죽은 요소가 건너뜀으로 나온다 | 심어서 — 0-(c) |
| 죽으면 완주 못 함이 나온다 | 죽여서 — 0-(d) |

**아직 안 한 것은 안 했다고 적었습니다** — 고장의 세기를 재는 눈이
없고(AK-a), 못 심는 까닭에서 권한과 자료가 한 문장에 묶여 있으며
(AK-b), 자가시험 한 판이 열 판 넘게 돕니다(AK-c). 그리고 검토가 찾은
넷은 **점검을 고쳐야 하는 것들이라 이 판에서 안 했습니다** — 8-b 에
무엇이 바뀌는지와 함께 적었습니다.

**그리고 이 표 자체가 두 번째로 일을 했습니다.** 「자료라 못 심었다」
와 「나온 값을 그대로 옮겼다」 둘 다 **제가 확인한 것보다 한 걸음 앞선
문장**이었고, 검토가 코드를 읽어 뒤집었습니다 — 「무엇으로 확인했나」
칸을 채울 때 **읽은 것과 돌린 것을 갈라 적어야** 한다는 뜻입니다.
