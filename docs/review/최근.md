## 2. [막1] `sc` 를 뽑아 놓고 지나갔습니다

`docs/배포-안내.md` 의 `sc` 셋이 PowerShell 에서 **`Set-Content` 별칭**
입니다. 빈 폴더에서 돌려 봤습니다.

```
Get-Command sc -All 로 보면
    sc      -> Alias        Set-Content
    sc.exe  -> Application  C:\Windows\system32\sc.exe

잘못) sc query Cloudflared
      -> 화면에 아무것도 안 나옴
      -> 'query' 라는 파일이 생기고 내용이 'Cloudflared'
```

**이번 판이 잡은 `curl` 과 정확히 같은 종류입니다** — 별칭이 exe 를
가리는 것. `curl` 은 잡고 `sc` 는 못 잡았습니다.

### 왜 놓쳤나

1단계는 목록을 안 짜기로 해 놓고, **2단계에서 다시 목록을 짰습니다**
(`명령 프롬프트|cmd|파워셸|검은 창|관리자 권한`). `sc` 도 `curl` 도 그
다섯 중 어느 것도 아닙니다.

**`sc` 는 1단계가 뽑은 23개 안에 분명히 있었습니다.** 뽑기는 제대로
뽑았고 눈으로 훑다가 넘어갔습니다 — 1판이 「뽑는 그물」 이 좁았다면
2판은 **「뽑아 놓고 안 본 것」** 입니다.

### 고친 것 — `sc` 를 `sc.exe` 로 다섯 곳

줄 번호는 **고친 뒤** 파일 기준입니다 (1장에 설명이 들어가 밀렸습니다).

| 줄 | 무엇 |
|---|---|
| 350 | 산문 — 「`sc.exe` 명령의 문법입니다」 |
| 353 | `config Cloudflared binPath= …` (8-3 의 핵심) |
| 366 | `query Cloudflared` (8-3 의 성공 판정) |
| 469 | 산문 — 11장의 확인 방법 |
| 473 | `qc Cloudflared` |

### 성공 판정 화면을 실제로 확인했습니다

이 노트북에 Cloudflared 가 실제로 돌고 있어 **진짜 화면**입니다.


문서가 「`STATE` 가 `4  RUNNING` 이면 됩니다」 라고 적은 그대로입니다.

## 3. 23개를 다시 — 눈으로 훑지 않고 판정을 적었습니다

`Get-Command <이름> -All` 로 전부 풀어 봤습니다.

| 이름 | 무엇으로 풀리나 | 판정 |
|---|---|---|
| `cd` | Alias → `Set-Location` | **돕니다** (`/d` 만 안 됩니다) |
| `sc` | **Alias → `Set-Content`** + Application | **안 됩니다** → `.exe` |
| `curl` | **Alias → `Invoke-WebRequest`** + Application | **안 됩니다** → `.exe` |
| `where` | **Alias → `Where-Object`** + Application | 안 됩니다 (문서에 없음) |
| `sc.exe` · `curl.exe` | Application | 돕니다 |
| `copy` | Alias → `Copy-Item` | **돕니다** — 위치 인자를 그대로 받습니다 (실제로 복사해 봤습니다) |
| `mkdir` | Function | **돕니다** (실제로 만들어 봤습니다) |
| `py` · `net` · `setx` · `timeout` | Application | 돕니다 |
| `run.bat` | **NOT FOUND** | **안 됩니다** → 앞에 `.\` |
| `New-Item` · `Get-ChildItem` · `Copy-Item` · `Out-Null` · `Stop-Process` · `Start-Process` · `Select-Object` | Cmdlet | 돕니다 |
| `Get-NetTCPConnection` · `Stop-ScheduledTask` · `Start-ScheduledTask` | Function | 돕니다 |
| `$env:…` · `.venv\Scripts\python.exe` | — | 돕니다 (구분자가 있어 상대 경로가 풀립니다) |
| README 148-151 의 `main.py` 등 | — | **명령이 아닙니다** — 파일 목록입니다 |
| 최근.md 의 `scripts/…` | — | **명령이 아닙니다** — 바뀐 파일 목록입니다 |

**「전부 돕니다」 한 줄로 넘기지 않았습니다.** `copy` 와 `mkdir` 은
별칭·함수인데도 도는 쪽이라, 이름만 보고는 갈 수 없어 실제로 돌려
봤습니다.

2. **보고에 「지웠습니다 · 통과」 라고 적은 것이 안 고쳐져 있었습니다.**
   한 사실을 두 곳(CLAUDE.md · 시험)에 적어 놓고 한쪽만 고쳤습니다 —
   이 프로젝트가 가장 자주 겪는 모양인데 제가 그것을 또 만들었습니다
3. **검사가 자기를 설명하는 글을 네 번 잡았습니다.** 트레이스백 ·
   URL 인코딩 · 확인 결과 줄 · 그리고 규칙을 설명하려고 CLAUDE.md 에
   넣은 **측정표**. 10장이 이름 붙여 둔 「금지하는 도구가 그것을
   설명하려고 스스로 담는다」 입니다.
   앞의 셋을 하나씩 막다가 넷째에 또 걸렸고, 그제야 **화살표로 설명
   줄을 한 곳에서 가르는** 방식으로 바꿨습니다 — 하나씩 막을 것이
   아니라 처음부터 갈랐어야 합니다
4. **`sc` 를 고치니 기존 시험 둘이 빨개졌습니다.** `test_ui_shift` 가
   8-3 의 그 줄을 `.exe` 없이 단언하고 있었습니다 — 규칙을 새로 만들면
   **그 규칙을 모르던 옛 시험이 규칙을 거스르는 쪽을 지킵니다.**
   `.exe` 까지 보도록 고치고 왜 필요한지 주석에 적었습니다
5. **보고가 증거로 인용한 잘못된 명령이 걸렸습니다** — 검사가 자기를
   설명하는 글을 잡은 **다섯 번째**입니다. 앞의 넷과 달리 이번엔
   **틀린 명령을 그대로 보여주는 것이 증거**라 문법으로는 가를 수
