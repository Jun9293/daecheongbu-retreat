## 1. 1단계 — 그물이 기울어 있었습니다 (실제 숫자)

지적이 맞았습니다. 재 보니 이랬습니다.

```
새 업무 제안 106개 중
  가장 가까운 기존 업무와 0낱말 겹침 …  25개
  가장 가까운 기존 업무와 1낱말 겹침 …  81개   ← 76%
```

**81개가 이미 있는 업무와 한 낱말이 겹칩니다.** 업무 이름은 짧고(중앙값
2낱말) 회의록 줄은 길어서, 두 낱말을 못 넘겨 "새 업무" 로 빠져나왔습니다.

표본 여덟 개를 보니 더 나빴습니다 — 대부분 할 일이 아니라 **논의 문장**이었고,
마크업까지 새고 있었습니다.

```
· 아웃리치에 담긴 가치 : 아웃리치를 준비/진행하며 확장되는 시선
· 외부강사 섭외의 경우 진행해보면서 대안 설정이 계속 필요할 것으로 예상됨
· 04.22 1차 구상안** ⇒ 외부강사 섭외결정 → …        ← `**` 가 그대로
```

### 무엇을 바꿨나

| | |
|---|---|
| 근거 | 그 줄 자신의 낱말 → **가장 가까운 기존 업무와 겹친 수** |
| 거르기 | 줄의 낱말이 **전부 보드에 이미 있으면** 안 냅니다 |
| 그물 | 할 일 꼬리말이 **줄 끝에** 있어야 합니다 (가운데면 서술문입니다) |
| 길이 | 60자 → **40자** |
| 마크업 | `**` · `~~` 를 걷어냅니다 |
| 중복 | 같은 줄이 두 번 나오면 한 번만 |

### 고친 뒤

```
새 업무 제안  106개 → 59개   (회의 50건 · 0개인 회의 26건)
```

### 4번 — **접지 않았습니다**

표본 열둘을 다시 보니 절반쯤이 진짜 할 일이었습니다.

```
O 포토존 찍을 수 있는 스케줄 상의 시간확보 필요   ← 가장 가까운 것: 「포토존」
O 참여/미참여 프로그램 확인 요청
O 세미나실 셀프조작 가능여부 확인 필요
O 시설과 최종 협의되면 금액 수정하기
X 각 중그룹에서 결정하기                        ← 막연함
X 소정M이 5월 안으로 기안 작성해볼 예정          ← 일정 메모
```

**남긴 이유가 둘입니다.**

1. 절반은 진짜 할 일이라 "대부분이 잡음" 이 아닙니다
2. **`가장 가까운 것: 「포토존」` 덕에 틀린 것을 한눈에 버릴 수 있습니다.**
   전에는 근거가 그 줄 자신의 낱말이라 아무 도움이 안 됐습니다

다만 이건 **표본 열둘의 눈대중**이고, 진짜 성적은 성적표를 채워야 나옵니다
(아래 5장). **채운 뒤 X 가 대부분이면 그때 접습니다.**

## 2. 2단계 — 전제가 숫자와 달랐습니다

지적은 "논의 제안이 거의 항상 5개고, 그래서 빈 목록(4-10 조건 4)이 사실상
작동하지 않는다" 였습니다. **세어 보니 그렇지 않았습니다.**

```
회의 50건 · 보드 96건 · 하한 2낱말

  논의 제안 개수별 회의 수
    0개 → 24건   ← 48%. 빈 목록은 실제로 나옵니다
    1개 →  2건
    2개 →  3건
    3개 →  3건
    4개 →  3건
    5개 → 15건   ← 30%
  합계 104개
```

5개까지 차는 회의는 30%이고, 그것들은 **본문이 2000~3000자인 큰 회의**입니다.
큰 회의가 여러 업무를 건드리는 것은 이상한 일이 아닙니다.

### 하한을 올리면 (숫자로 본 것)

```
하한 2낱말 → 총 104개 · 빈 목록 24건 · 5개꽉 15건
하한 3낱말 → 총  35개 · 빈 목록 38건 · 5개꽉  4건
하한 4낱말 → 총   4개 · 빈 목록 47건 · 5개꽉  0건
```

**올리지 않았습니다.** 3으로 올리면 104→35 인데, 잘려 나가는 것에
`GBS 교재 출력·제작 ← 교재, 제작` 처럼 **맞는 것들이 섞여 있습니다.**
빈 목록이 이미 48% 나오므로 조건 4 가 안 되는 것도 아닙니다.

### 대신 한 것 — 흔한 낱말 거르기

보드에서 여러 업무 이름에 두루 나오는 낱말을 셌습니다.

```
제작 — 업무 이름 11개에      게시·모집·전달·영상 — 5개에
준비·연습·확정·완료 — 6개에   GBS·수련회·기도회 — 4개에
```

**겹친 낱말 중 하나는 흔하지 않아야** 합니다. `확인, 조정` 처럼 아무 업무에나
있는 낱말만으로는 관계가 아닙니다.

```
104개 → 95개   (빈 목록 24건 그대로 · 5개꽉 15→11건)
```

아홉 개만 줄지만 **줄어드는 아홉이 정확히 가장 약한 것들**입니다.

### 그리고 — 잘렸으면 잘렸다고 말합니다

5개를 넘으면 조용히 잘리고 있었습니다. 이제 한 줄이 붙습니다 —
`이름이 겹치는 업무가 12건 더 있습니다`. (브라우저에서 확인)

## 3. 3단계 — 형광펜에 뜻을 붙이지 않습니다

`⟨미완료?⟩` → **`⟨형광펜⟩`**.

물음표가 있어도 뜻을 주장합니다. 나중에 읽는 사람은 물음표를 안 읽고
"미완료" 만 읽고, 근거가 2/20 인 읽기가 **본문에 박힌 채로 돌아다닙니다.**

`⟨형광펜⟩` 은 **칠해져 있었다는 사실만** 말합니다. 그건 확실하고 원본의
정보도 그대로 지켜집니다 (6-9 — 지어낸 기록을 심지 않는다). 뜻이 밝혀지면
그때 붙입니다. 화면에도 같은 말이 적혀 있습니다 —

> 본문의 `⟨형광펜⟩` 은 원본에서 그 대목이 **칠해져 있었다**는 표시입니다.
> **뜻은 붙이지 않았습니다** — 회의 50건에서 형광펜 22곳 중 두 번 이상 나온
> 문장은 2개뿐이라, '안 끝난 것' 이라고 읽을 근거가 약합니다.

## 10. 판단이 들어간 자리 (발췌)

### 지적의 전제가 숫자와 다를 때

2단계는 "빈 목록이 사실상 작동하지 않는다" 를 전제로 하한을 올리라고 했습니다.
**세어 보니 48%가 이미 빈 목록**이었고, 하한을 3으로 올리면 맞는 제안까지
잘려 나갔습니다. 그래서 **올리지 않고 숫자를 그대로 보고**합니다 —
"숫자를 보고 정한다. 짐작으로 올리지 않는다" 는 지시가 올리라는 뜻이 아니라
**숫자에 따르라**는 뜻이라고 읽었습니다.

대신 숫자가 실제로 가리킨 약점(2낱말 겹침이 66%)에는 흔한 낱말 조건으로
답했습니다.

### 새 업무를 접지 않은 판단

"대부분이 잡음이면 접는다" 가 조건이었습니다. 고친 뒤 표본 열둘에서 절반이
진짜 할 일이었고, 무엇보다 **`가장 가까운 것` 이 붙으면서 틀린 것을 버리는
값이 싸졌습니다.** 그래서 남겼고, **성적표를 채운 뒤 X 가 대부분이면 그때
접는다**고 적어 두었습니다 — 판단을 미룬 것이 아니라 **판단 기준과 시점을
정한 것**입니다.
