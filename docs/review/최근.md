# 5. 사람이 돌릴 것 — 영수증 잇기

```powershell
cd "C:\Users\user\Desktop\대청부-수련회-시스템"
.venv\Scripts\python.exe scripts/영수증잇기옮기기.py
```

미리보기가 「잇기 줄이 하나도 없는 영수증 12장」 이면(4장과 같으면) 이어서:

```powershell
.venv\Scripts\python.exe scripts/영수증잇기옮기기.py --실행
```

「이었습니다: 12줄 · … 이을 것 0장」 이면 닫힌 것이다. 미리보기 수가 12 가 아니면 `--실행` 을 돌리지 말고 알린다(11-2).

**누가 돌리나가 부딪힌다** — 지시문은 「값을 채우는 전환이 필요하면 사람이 돌리는 쪽으로 두고 사람칸에 적는다」 이고, CLAUDE.md 11-2 는 미리보기·사본·다시 세기가 있는 운영 명령은 작업하는 쪽이 돌린다고 한다. 이 판은 **지시문을 따랐고** 11-2 를 고치지 않았다. 사람칸 「정할 것」 ①.

**창이 열린 동안** — 재시작(16:11:44)부터 스크립트를 돌릴 때까지 운영의 영수증 12장이 지출에 안 보이고 「영수증 없음」 수가 그만큼 늘어 보인다. 옛 영수증을 번호로 잇는 것은 409 로 막았다. **새 영수증을 같은 지출에 또 붙이는 것은 못 막는다**(봐둘것 BB-d).

# 6. 판단이 들어간 자리

- **잇기 표 + 「처음 붙은 지출」 을 남긴 것** — expense_id 를 걷으면 영수증의 회차를 알 칸(retreat_id)을 새로 붙이고 채워야 한다 — 값 채우기가 하나 더 생긴다. 남기면 자동 번호 셈(`next_receipt_number`)과 전환 스크립트가 그대로 쓴다. 대신 「걸린 곳」 과 헷갈릴 수 있어 모델 주석과 8장에 「걸린 곳이 아니다」 를 적었다
- **마지막 한 곳에서도 떼게 둔 것** — 지시문이 「잘못 붙인 영수증이 영영 남는다」 를 풀라고 했다. 뗀 영수증은 번호로 다시 잇는다. 논의(4-9)는 마지막 한 곳 떼기를 막지만, 영수증은 붙을 곳 없이도 번호로 찾을 수 있어 다르게 뒀다
- **번호로 잇는 것** — 행마다 영수증 목록을 실으면 지출 × 영수증만큼 화면이 커진다(시트는 백 줄 · 백 장 남짓)
- **원본 번호를 글자 · 겹침 허용** — 사람이 매긴 번호라 적힌 그대로 두고, 겹침을 막으면 들여오기가 거기서 멈춘다. 열쇠는 자동 번호다
- **계좌를 가르는 규칙의 자리** — 들여오기 스크립트(차례 6)에 두고, 고치는 길(차례 5)이 같은 규칙을 쓰게 되면 `domain/budget.py` 로 올린다. 지금은 가르는 코드가 없다(7-4)
- **16px 을 `.expform` 과 `.kv` 전체에** — 휴대폰 사파리는 16px 아래 칸을 누르면 확대한다. 계좌 칸만 올리면 한 폼 안에서 칸 크기가 갈린다. 설정의 다른 탭 입력도 좁은 화면에서 16px 이 된다(두 번째 검토 N-2)
