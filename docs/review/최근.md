## 판단이 들어간 자리 (발췌)

- **게이트를 목록→스키마로 뒤집은 것** — 지시문은 「목록을 차이만큼
  넓히고, 모델과 견주는 시험」 을 그렸는데, 넓힌 목록도 다음 칸이 생기면
  또 목록이다. 기본을 「본다」 로 뒤집으면 새 칸이 자동으로 걸리고, 사람이
  관리하는 것은 **안 볼 이유**뿐이 된다 — 견주는 시험(g01)과 심는
  시험(g02)은 지시문 그대로 있다
- **제외 52칸의 기준** — 값의 형태가 코드로 정해진 것만(enum·키·해시·
  시각·색·난수·푸시 키). 자유 텍스트는 분류어처럼 보여도 전부 본다
  (level1·quantity·user note 류) — 오탐 비용은 dev DB 스캔 몇 ms 뿐이고,
  못 본 비용은 공개 커밋이다
- **stash 에 이름을 넣고 u= 를 없앤 것** — 가드(길이 검사)로 남기는 대신
  어긋날 자리 자체를 지웠다. take 가 (원문, 이름) 튜플이 되면서 옛 시험
  하나(마무리03b)의 기대값을 튜플로 옮겼다
