## 고친 것

### 1. 실명이 든 것은 `data/`, 저장소에는 가명만

`data/*.real.md` 를 `.gitignore` 에 더했습니다. **실제로 확인했습니다.**

```
> git check-ignore -v data/제안-1판.real.md
.gitignore:27:data/*.real.md    data/제안-1판.real.md
```

**채점은 `.real.md` 로 합니다** — 사람이 채점할 때는 실명이 보여야 합니다.
저장소에는 `--공개` 로 만든 사본만 올립니다.

```
적었습니다: data\제안-1판.real.md  (20개)
공개본: docs\review\제안-1판.md  (이름 4곳을 바꿨습니다)
```

익명화 로직을 새로 쓰지 않고 `anonymize.py` 의 `swap()` 을 부릅니다 —
**바꾸는 곳은 하나입니다.** 0곳이면 *"원래 없었거나 못 찾은 것"* 이라고
말합니다. 없었던 것과 못 찾은 것이 같은 모양이면 안 됩니다.

### 2. 찾는 것과 바꾸는 것은 다른 일입니다

| | 하는 일 | 경계 |
|---|---|---|
| `anonymize.py` | **바꾼다** | 엄격 — 앞뒤가 한글·영문·숫자면 건너뜀 |
| `check_names.py` | **찾기만 한다** | 느슨 — 글자가 들어 있으면 전부 짚음 |

경계 규칙은 **그대로 뒀습니다.** 느슨하게 하면 `필요한`·`진행` 이 깨지던
문제가 돌아옵니다. 대신 느슨하게 *찾는* 도구를 따로 두었습니다.

> 오탐은 사람이 한 번 보고 넘기면 되지만,
> **못 찾은 실명은 공개 저장소로 나갑니다.**

- 대응표는 `anonymize.py` 의 `load_map()` 을 그대로 부릅니다 — 두 곳에서
  읽으면 한쪽만 구조를 잘못 읽습니다. **이번에 정확히 그랬습니다**
- **실명을 화면에 그대로 찍지 않습니다**(`지◯`). 검사 결과가 로그·채팅으로
  돌아다니는데, 거기 실명이 찍히면 막으려던 것을 검사가 하는 셈입니다
- 넘긴 목록 `docs/이름-확인됨.txt` 에 **왜 넘기는지**를 함께 적습니다.
  `*` 는 어느 파일에서든 넘깁니다 — 한두 글자 이름(`진`→진행·사진,
  `요한`→필요한)은 낱말 안에 늘 들어가고, 파일마다 적으면
  `최근.md` 가 **매 작업마다 빨개져** 사람이 검사를 무시하기 시작합니다
  (4-11 과 같은 자리)

### 3. 아무것도 안 보는 것은 통과가 아닙니다

`tests/test_check_names.py` 8개. **읽은 실명이 0개면 실패합니다** —
빈 대응표를 물려 확인했습니다(종료 코드 2).

**오늘 같은 모양이 셋이었습니다** — 이 검사, `더있음` 을 제안으로 센 것,

막으려던 것을 시험이 합니다.

> **검사가 스스로에게 걸렸습니다.** `check_names.py` 독스트링에 예로

### 틈이 둘입니다

**(가) 성이 붙은 이름** — `(?<!WORDISH)` 가 앞의 성 때문에 실패합니다.
대응표에 성 붙은 형태를 넣지 않기로 했으므로(같은 사람이 두 줄이 됩니다)
**제 판단으로 넣지 않았습니다.**

**(나) `M` 뒤에 조사** — `(real)(M?)(?!WORDISH)` 에서 `M` 다음이 `으` 라
실패하고, `M` 을 안 먹으면 `M` 자체가 `WORDISH` 라 또 실패합니다.

> **(나)는 좁고 안전한 고침이 있습니다.** `M` 이 실제로 붙었을 때만 뒤의
> 한글을 허용하면 됩니다. `필요한`·`진행` 은 `M` 이 없으므로 영향이 없고,
> 낱말 안에 든 것은 여전히 앞의 lookbehind 가 막습니다.
> **"경계 규칙을 그대로 둔다" 는 지시가 있어 건드리지 않았습니다.**

### 한쪽은 넣었고 한쪽은 못 넣었습니다

두 글자짜리 한 이름은 대응표에 넣었습니다 — **글자 수를 지켰습니다** (11-2 의 「바꿀 때 지킨 것」).

`최지◯` 은 넣지 않았습니다. 운영 자료를 훑어 보니 **`지◯` 앞에 오는 성이
둘**입니다.

```
앞='문'  →  문지◯
앞='최'  →  최지◯
앞=''    →  지◯ (홀로)
```

대응표에는 `["지◯", "다은"]` **한 줄뿐**이라, 홀로 선 것은 둘 중 누구든
`다은` 이 됩니다. **두 사람이면 이미 한 사람으로 합쳐지고 있습니다.**

물어볼 것 셋 —

1. 문◯◯ 과 최◯◯ 은 같은 사람입니까, 다른 사람입니까?
2. 다른 사람이면 한 줄로는 둘을 가릴 수 없습니다. 성을 붙인 세 글자
   두 줄로 넣을까요?
3. 같은 사람이면 어느 성이 맞습니까? 한쪽은 오기일 수 있습니다.

## 이번에 걸린 것

1. **검사가 아무것도 안 보면서 초록을 냈습니다** (`list(m.keys())`).
   있으나 마나가 아니라 **있다고 믿게 만들어 더 나쁩니다**
2. **검사가 스스로에게 걸렸습니다** — 독스트링에 실명을 예로 적었습니다
3. **넘긴 목록이 자기 자신에 걸렸습니다** — 넘길 낱말을 적는 파일이라
   당연한데, 제외를 안 넣어 두었습니다

   시험만의 문제가 아니라 인자로 아무 경로나 줄 수 있는 실제 버그였습니다
5. **`\n` 이 편집 명령에서 실제 줄바꿈으로 풀려** 세 번 문법이 깨졌습니다.
   `chr(92)` 로 만들어 피했습니다
