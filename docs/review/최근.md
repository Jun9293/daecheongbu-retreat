## 판단이 들어간 자리 (발췌)

- **키 없는 부서의 되돌림** — `can_edit_department_by_key` 는 양쪽 키가
  있을 때만 키로 견주고, 없으면 기존 id 비교로 되돌아간다. 키가 없는
  부서는 구설계 데이터뿐이고, None==None 으로 통과시키면 소속 없는
  사람이 소속 없는 부서를 고치게 된다
- **게이트가 이름을 안 찍는 이유** — 찍으면 그 출력(터미널·로그)이 또
  실명이 새는 자리가 된다. 자리·수만 말하고 지우는 명령을 안내한다
- **이미지 검사가 「새 이미지」만 보는 이유** — 기존 7개는 사람이 이미
  확인했고, 매번 전부를 물으면 확인 기록이 형식이 된다. 마지막 커밋
  (`git ls-tree HEAD`)에 없던 것만 묻는다
- **k05 의 허용 목록** — 남은 id 비교를 지우는 대신 파일·비교식 이름으로
  적어 두었다. 지우면 구설계 되돌림이 사라지고, 안 적으면 새 id 비교가
  조용히 들어온다. 캡처값의 트레일링 `)]` 는 정규화해 견준다
- **환급의 빈 값** — 원래 「숨는 방향보다 보이는 방향」으로 환급 쪽에
  두었으나, 지출자를 안 적은 것은 개인 지출이라는 뜻이 아니라서 넷 중
  빈 값만 방향을 바꿨다. 지출자 없는 지출은 목록에서 그대로 보인다
