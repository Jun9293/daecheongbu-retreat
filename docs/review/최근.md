## 1. 무엇을 했는지

**A — 초대 링크에서 자리표시자를 없앤다**

- 앞선 작업에서 `DCB_BASE_URL` 과 `auth.invite_url()` 은 이미 들어가 있었습니다. 남은 것만 마저 했습니다.
- 재발급하면 옛 링크가 죽는다는 안내를 **화면·`create_admin.py`·`merge_users.py`** 세 곳에 붙였습니다.
- 자리표시자 문자열을 **설명하는 글에서도** 걷어냈습니다 (`config.py` · `auth.py` · 배포 안내 · 현황 브리핑).
- A 의 시험을 `tests/test_admin_users.py` 에서 `tests/test_invite.py` 로 옮기고, **저장소 전체를 훑는 시험**을 더했습니다.

**B — 달력에서 바로 상세 패널을 연다**

- 패널의 화면을 `templates/partials/drawer.html` 로, 코드를 `static/js/drawer.js` 로 빼냈습니다. **보드와 달력이 그 한 벌을 같이 씁니다.**
- `board.js` 는 1330줄 → 505줄. 패널 코드가 전부 빠지고 "보드는 이렇게 고쳐 그린다"만 `Drawer.init({...})` 로 남았습니다.
- `static/js/calendar.js` 를 새로 만들었습니다 — 점을 눌러 패널을 열고, 상태가 바뀌면 **점만** 다시 칠합니다(다시 불러오지 않습니다).
- `docs/checks/drawer.js` 가 어느 화면인지 알아보고 **두 화면 모두에서** 돌도록 고쳤습니다.

**C — 큰 파일과 링크 첨부**

- 상한 25MB → **200MB**, 확장자 27 → **44가지**(RAW·TIFF·7z 등).
- 업로드를 **조각으로 받아 바로 디스크에 씁니다.** 끊기거나 거절당하면 **반쯤 쓰인 파일을 지웁니다.**
- 디스크 여유가 없으면 **이유를 말하고 거절합니다**(507). 자가진단에 `디스크 여유` 항목을 더했습니다.
- 백업이 업로드 폴더를 **바뀐 것만** 복사합니다(안 바뀌면 지난 zip 에 하드링크). 개수(30)뿐 아니라 **총합(10GB)** 으로도 오래된 것부터 지웁니다. 이번 백업이 몇 MB 인지 찍습니다.

### B — 패널을 어떻게 나눴는지

| 무엇 | 어디 | 누가 쓰나 |

| 패널의 화면 | `app/templates/partials/drawer.html` | `board.html` · `calendar.html` 이 **같은 파일을 include** |

`test_08b_패널이_한_벌이다` 가 **경로가 하나인지**를 봅니다 — 두 화면이 같은 파일을
include 하는지, `board.js` 에 `renderDrawer`·`renderLog`·`renderFiles`·`statMenu` 가
**남아 있지 않은지**. "둘 다 되더라" 로는 베껴 놓은 것을 잡을 수 없습니다.

### C-4 — 큰 파일이 실제로 오가는가

**앱 쪽은 됩니다.** `testdata/IYC 도면.pdf`(**162.1MB**, 한글 이름 + 공백)로 확인했습니다.

| | 시간 | 속도 | 결과 |
|---|---|---|---|
| 올리기 | 0.7초 | 218MB/s | 성공 |
| 내려받기 | 0.5초 | 339MB/s | 성공 · **sha256 동일** |

무작위 164MB 로도 같은 결과였습니다(0.7초 / 0.6초, sha256 동일). 둘 다 **로컬(127.0.0.1:8002)** 입니다.

**터널 쪽은 못 넘깁니다. 되는 척하지 않겠습니다.**

바깥에서 들어오는 길(`https://retreat.recba12.com`, Cloudflare 무료 터널)로 본문을 보내 봤습니다.

| 보낸 크기 | 결과 |
|---|---|
| 5MB | HTTP 200 · 2.7초 (1.83MB/s) |
| 50MB | HTTP 200 · 24.9초 (2.01MB/s) |
| 100MB | **31.4초에 연결 끊김** |
| 120MB | **31.1초에 연결 끊김** |
| 20MB 를 60초에 걸쳐 천천히 | **12MB 째, 36.6초에 끊김** |

마지막 줄이 결정적입니다 — **크기가 아니라 시간입니다.** 본문을 보내는 데
**30초를 넘기면 끊깁니다.** 재 본 올리기 속도가 **약 2MB/s** 이므로 실제 한계는
**60MB 언저리**입니다. 162MB 는 그 길로 올라가지 못합니다.

**다만 이 측정은 로그인하지 않은 요청입니다.** 그 경우 서버가 본문을 다 읽기 전에
로그인 화면으로 답해 버리므로, 끊긴 것이 Cloudflare 때문인지 서버가 먼저 답해서인지
**단정할 수 없습니다.** 확실히 하려면 **서버를 새 코드로 다시 켠 뒤** 로그인한 채로
100MB 를 한 번 올려 봐야 합니다. 지금 도는 운영 서버는 옛 코드(상한 25MB)라
그 시험 자체가 안 됩니다.

**그래서 상한은 200MB 로 두었습니다.** 앱은 감당하고, 터널은 나중에 나아질 수 있고
(유료 전환·다른 경로), `DCB_MAX_ATTACHMENT_MB` 로 코드를 안 고치고 낮출 수 있습니다.
대신 첨부 탭에 **"영상처럼 큰 것은 올리지 말고 링크로 붙이세요"** 를 적어 두었습니다 —
링크 첨부를 넣은 이유가 바로 이것입니다.

| `DISK_FREE_FLOOR_BYTES` | **2GB** | `app/config.py` | 이 아래면 올리기를 **거절**합니다. 받아 놓고 나중에 깨지는 것보다 낫습니다. `DCB_DISK_FLOOR_MB` |

## 6. 판단이 들어간 자리

### 6-1. 저장소 전체 훑기를 git 에게 물어본다 (A-4)

목록을 손으로 적는 대신 git 에게 묻습니다. 규칙이 `.gitignore` 한 곳에만 있게 됩니다.

```python
def repo_files():
    out = subprocess.run(
        ["git", "ls-files", "--cached", "--others", "--exclude-standard"],
        cwd=ROOT, capture_output=True, text=True, encoding="utf-8")
    if out.returncode != 0:                      # git 이 없는 곳에서는 건너뛴다
        return None
    return [ROOT / line for line in out.stdout.splitlines() if line.strip()]
```

시험 파일 자신이 걸리지 않도록 찾는 문자열을 조립해서 만듭니다.

### 6-2. 패널을 나누는 경계 (B-11)

`drawer.js` 가 화면에게 묻는 것은 이것뿐입니다. 나머지는 전부 패널이 합니다.

```js
Drawer.init({
  canGoTo: true,                     // '이동' 메뉴를 낼까 (달력은 false)
  meta: runId => META[runId] || null, // 열기 전에 제목만 미리
  onClose: unlink,
  afterLayout: drawWires,
  goTo: id => { … },                 // 보드는 스크롤 + 깜빡임
  onStatus: applyStatus,             // 보드는 바를, 달력은 점을
  onDates: applySavedDates,
  onAssignee: applyAssignee,
  isTaskClick: el => el.closest('.bar[data-run],[data-go]'),
  openFromUrl: run => { … },
});
```

달력 쪽은 이렇습니다 — **`이동` 을 내지 않는 것**이 판단입니다. 스크롤해서 갈 자리가
없는데 메뉴만 있으면 눌러도 아무 일이 없습니다.

```js
Drawer.init({
  canGoTo: false,
  meta: runId => ({title: titleOf(runId)}),   // 이 달에 없는 업무도 열 수 있게
  onStatus: applyStatus,
  isTaskClick: el => el.closest('.cal-dot'),
});
```

`meta` 가 **null 을 돌려주지 않는 것**도 판단입니다. `/calendar?task=123` 의 그 업무가
이번 달에 없을 수 있는데, 없다고 안 열면 알림에서 들어온 사람이 빈 화면을 봅니다.

### 6-3. 달력의 점이 상태를 따라가는 법 (B-8)

```js
function applyStatus(runId, status, view) {
  const hide = onlyOpen() && status === '완료';
  dots(runId).forEach(dot => {
    dot.style.background = view.background;
    dot.style.borderColor = view.border;
    dot.classList.toggle('done', status === '완료');
    // 기한 초과는 **날짜에서 계산한 것**이다 (4-10). 구조가 실어 보낸 값을
    // 그대로 쓰되, 완료되면 더 이상 초과가 아니다.
    dot.classList.toggle('late', dot.dataset.overdue === '1' && status !== '완료');
    dot.classList.toggle('filtered', hide);
  });
}
```

- **다시 불러오지 않습니다.** 불러오면 보던 달을 잃습니다.
- `미완료만` 이 켜져 있으면 완료된 점을 감춥니다 — **보드가 하는 것과 같게** 했습니다.
  두 화면이 같은 말로 다르게 굴면 어느 쪽이 맞는지 알 수 없어집니다.
- 칩 상태는 **구조가 실어 보낸 값**(`.calbar[data-only-open]`)을 읽습니다.
  처음에는 칩의 클래스와 주소를 뒤져 알아냈는데, 범위 칩과 헷갈려 **조용히 반대로** 판단했습니다.

### 6-4. 올린 것을 조각으로 받고, 끊기면 지운다 (C-20)

```python
    size = 0
    try:
        with path.open("wb") as out:
            while chunk := await upload.read(CHUNK_BYTES):
                size += len(chunk)
                if size > MAX_ATTACHMENT_BYTES:
                    raise HTTPException(status_code=400, detail=…)
                # 받는 동안에도 여유를 본다. 미리 본 값은 짐작일 뿐이고,
                # 같은 시각에 다른 사람이 올리고 있을 수도 있다.
                if size % DISK_RECHECK_BYTES < CHUNK_BYTES:
                    _require_disk(0)
                out.write(chunk)
        if not size:
            raise HTTPException(status_code=400, detail="빈 파일은 올릴 수 없습니다.")
    except BaseException:
        # 취소·끊김·거절 — 어느 쪽이든 반쯤 쓰인 파일을 남기지 않는다.
        # ClientDisconnect 는 HTTPException 이 아니므로 BaseException 으로 받는다.
        path.unlink(missing_ok=True)
        raise
```

`except Exception` 이 아니라 `BaseException` 인 것이 요점입니다 — 취소했을 때 오는
`ClientDisconnect` 는 `Exception` 계열이 아닐 수 있어서, 좁게 잡으면 **정확히 취소했을 때만**
조각이 남습니다.

### 6-5. 백업이 바뀐 것만 복사하는 법 (C-15)

되돌리는 절차를 **바꾸지 않는 것**이 조건이었습니다. 날짜마다 `uploads-<날짜>.zip` 이
있어야 하고, 같은 날짜끼리 셋을 함께 되돌리면 됩니다. 그래서 다시 묶는 대신 **하드링크**를 겁니다.

```python
    if previous is not None:
        # 같은 초에 두 번 돌면 지난 것과 이번 것의 이름이 같다. 자기 자신에게
        # 링크를 걸 수는 없으므로 그대로 둔다 — DB 스냅샷이 덮어쓰는 것과 같다.
        if previous == target:
            return target, False
        target.unlink(missing_ok=True)
        try:
            os.link(previous, target)
        except OSError:                     # 하드링크가 안 되는 곳이면 그냥 복사
            shutil.copy2(previous, target)
```

바뀌었는지는 **이름·크기·수정시각**으로 봅니다. 내용을 다 읽어 해시하면 200MB 짜리를
매일 새벽 전부 읽게 되는데, 그건 통째로 복사하는 것과 비용이 다르지 않습니다.
