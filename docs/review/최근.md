# 4. 판단이 들어간 자리

1. **묶음표의 열쇠를 「값 전체」 가 아니라 「찾을 말」 로 두었다.** 지시는 「시트 값에서 쓸 이름으로 가는 표」 였는데, 그 값 몇 개에 **빌려주신 분의 성함과 전화번호가 그대로 들어 있다** — 값을 열쇠로 적으면 그 성함이 이 공개 저장소에 들어옵니다(11-2 의 그 자리). 그래서 표를 「이 말이 구분 값에 들어 있으면 이 묶음」 으로 두고 **찾는 말은 깨끗한 낱말만** 적었다. 표에 없으면 멈추고 그 값을 말하는 것(사람이 한 줄 더한다)은 지시 그대로다.
2. **비고는 `EquipmentItem.note` 로 가고 「비어 있을 때만」 적는다** — `EquipmentRun` 에는 note 칸이 없다(도막 1·2 의 표에 없다). 지시가 「비고는 note」 라고만 해서 있는 칸으로 보냈다. 처음엔 문서가 「새로 만들 때만」 이라고 적고 코드는 「빈 note 도 채운다」 로 갈려 있었는데(검토가 잡았다 — 운영에서 7줄이 그 갈래를 밟는다), **코드 쪽을 남기고 문서를 고쳤다**: 채우는 것은 정보를 더하고 아무것도 안 지우는 반면, 안 채우면 시트에 있는 메모가 영영 안 들어온다. 적혀 있는 메모는 절대 안 민다(`b02b` 가 둘 다 잰다). 회차마다 다른 비고를 담으려면 run 에 칸이 필요하고 그건 이 도막 밖이다.
3. **그물은 양쪽으로 틀린다 — 넓은 쪽에 두었다.** 거르는 자국은 지시가 정한 둘(전화꼴 · 이름 뒤 `M`·`썬`·`언니`·`님`)이다.
   - **못 잡는 쪽**: 성만 있거나 아무 말도 안 붙은 이름, 「◯◯ 님」 처럼 사이에 빈칸이 있는 것. 마지막 그물은 **멈춘 자리를 사람이 보는 것**이다.
   - **과하게 잡는 쪽**(검토가 재서 짚음): 「하나님」·「목사님」 같은 멀쩡한 말과 「사이즈M」 같은 물품 표기도 걸려 **그 줄의 비고가 통째로 버려진다.** 이름과 모양이 같아 기계가 못 가르는 자리라, 버리는 쪽(안전한 방향)에 두고 **버린 수를 찍어** 사람이 시트에서 다시 읽게 했다. 총무 시트에서 11줄이 그렇게 버려진다.
   - **전화는 구분자 없이 붙여 쓴 것도** 잡게 넓혔다(검토가 재서 짚음 — 4-12 가 예로 드는 표기가 그 꼴이다). 지금 두 시트에는 0건이지만 남은 탭(인계 15·16)에서 0 이라는 보장이 없다.
   - **수량 칸에는 그물이 없다** — 「A3 :11, A4 : 11」 이 그대로 와야 해서다. 사람이 거기에 이름을 적으면 들어온다(검토가 짚음 · 4-18 에 적었다).

   실명 대응표에 기대지 않은 이유는 시트의 외부인이 애초에 거기 없기 때문이다(대응표는 우리 봉사자 이름이다).

8. **(검토 뒤) 멈출 때 구분 값을 그대로 찍는 것은 그대로 두었다** — 지시가 「그 값을 말한다」 였고, 사람이 표에 무엇을 더할지 알려면 값을 봐야 한다. 다만 그 값에 성함이 섞여 있을 수 있어 **「보고나 커밋 메시지에 옮겨 적지 마세요」** 한 줄을 함께 찍는다(11-2 의 「옮겨 적고 싶어지는 순간」).
