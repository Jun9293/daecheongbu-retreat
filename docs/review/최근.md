# 10. 「확인했습니다」 가 사실인지 (스스로 보기)

| 이 보고의 말 | 무엇으로 확인했나 |
|---|---|
| 1장·2-(b)·4-(a) 의 모든 수 | `data/app.db` 를 `mode=ro` 로 열어 센 값. 표마다 쿼리를 함께 적었다 |
| 「노션 페이지 id 를 저장하지 않는다」 | 코드 세 자리를 따라가 값이 `p.stem` 인 것을 보고, **실제 값의 길이 분포와 16진수 여부**를 세어 확인했다 |
| 「영수증 1장에 지출 여럿이 안 된다」 | 스키마를 봤다 — `expense_id` 가 단일 FK 이고 이어 주는 표가 없다 |
| 「게이트가 계좌 꼴을 안 잡는다」 | **넣고 돌렸다.** 그리고 같은 자리에 대응표 표기를 심어 **잡히는 것**까지 봤다 — 안 그러면 `exit=0` 이 「검사가 안 돌았다」 와 구별되지 않는다 |
| 「고친 파일이 하나뿐이다」 | 시험용 줄을 지운 뒤 `git status --short` 가 빈 것을 보고 나서 이 파일을 썼다 |
| 「셋 다 지어낸 자리표시자다」 | **틀렸습니다.** 하나는 저장소의 placeholder 를 가져온 것이었고, 그 숫자가 운영 자료 두 행과 같았습니다. 게다가 제가 지어낸 다른 하나도 한 행과 숫자가 같았습니다 — 다섯 행을 읽어 **세 가지 방식으로 견주어** 알았습니다(값은 한 자리도 안 찍었습니다). **보고에서 숫자를 전부 뺐습니다** |
| 「관련업무 링크 12개」 | **틀렸습니다** — `(id, 목록)` 튜플의 길이를 더해 6×2 를 셌습니다. 검토가 8이라고 해서 **다시 세어** 8이 맞았습니다. 기계로 센 값도 **무엇을 셌는지** 봐야 합니다 |
| 「서버가 그대로 돌고 있다」 | **요청을 보내 303 을 받았다.** 그리고 PID 를 다시 셌더니 앞 판(1912)과 **달랐다** — 「그대로」 라고 적었던 줄을 지우고 실제 값(13984)으로 고쳤다. 앞 판의 값을 옮겨 적는 것은 확인이 아니다 |
| 「앱에서 만든 행을 가릴 근거가 없다」 | 네 후보를 하나씩 열어 봤다 — 그중 `origin` 은 **코드가 같은 값을 박는 줄**(`tasks.py:134`)을 직접 봤다 |

**아직 확인하지 않은 것** — 원본(노션·시트)을 **열어 보지 않았습니다.**
이 도막은 앱 쪽만 셌습니다. 그래서 「원본에 몇 건이 있는가」 와 「무엇이
빠졌는가」 는 이 보고에 없습니다.
