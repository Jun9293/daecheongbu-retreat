## 4. 13번(확장자)이 원래 버그였는가 — **아닙니다. 다만 옆에 진짜가 있었습니다.**

**지적하신 `보고서..pdf` 는 나지 않았습니다.** `TaskAttachment.ext` 는
`original_name.rpartition(".")` 의 **뒤쪽**을 돌려주므로 점을 품지 않습니다.
`시안.pdf` → `"pdf"` 입니다. 그래서 `f"{name}.{ext}"` 로 점이 두 번 찍힐 일이
없었습니다. `.lstrip('.')` 는 **그쪽이 바뀌었을 때를 막는 것**이지 지금 있는
버그를 고친 것이 아닙니다.

**그런데 같은 줄에 진짜 문제가 있었습니다.**

```python
>>> Path("보고서.").suffix
'.'        # ← 빈 문자열이 아니다
```

`if not Path(name).suffix` 가 `"."` 을 "확장자가 있다" 로 읽어 되붙이기를
건너뜁니다. 그래서 `시안.pdf` 를 **`보고서.` 로 바꾸면 확장자가 조용히
사라졌습니다.** 끝의 점과 공백을 먼저 털고, 그러고 나서 비면 거절합니다.
`test_r13b` 가 그 자리를 지키고, 첫 줄에서 `Path("보고서.").suffix == "."` 을
확인해 **전제가 바뀌면 시험이 먼저 알려주게** 해 두었습니다.

## 9. 판단이 들어간 자리

**달력의 숫자는 세어서 다시 적습니다.** 더하고 빼면 한 번 어긋난 뒤로 영영
어긋납니다. `recount()` 가 `외 N건`·`날짜 없는 업무`·위쪽 건수를 매번 다시 셉니다
(`test_r03b` 가 그 함수 안에 `++`/`--` 가 없는지 봅니다).

**`onDepartment` 는 달력에서도 기본값(새로고침)을 씁니다.** 담당팀을 옮기면
부서 색이 바뀌는데, 점 색만 갈아 끼우면 `우리 부서` 범위와도 어긋납니다.
통째로 다시 그리는 것이 맞아서 그렇게 두고 이유를 `__unused` 에 적었습니다.

**터널 한계는 막는 선이 아니라 알려 주는 선입니다.** 집 안 회선에서는 200MB 도
올라가므로, 넘는다고 거절하면 **되는 것을 못 하게** 만듭니다. 그래서 묻고,
"예" 를 고르면 그대로 보냅니다.

**`except BaseException` 의 이유를 고쳤습니다.** `ClientDisconnect` 는
`Exception` 하위라 좁게 잡아도 걸립니다. 넓게 잡아야 하는 진짜 이유는
**`asyncio.CancelledError`** 이고(3.8부터 `BaseException` 직속), 사람이 취소를
누르면 그것으로 깨어납니다. 이유가 틀린 채로 두면 다음에 누가 좁힙니다.
