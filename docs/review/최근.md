## 1. 무엇을 했나

### 1단계 — `title` 을 조립하는 곳을 하나로

`board.paint_of` 가 **완성된 문장**을 함께 돌려줍니다. 만드는 곳은
`board.tooltip_of` 하나입니다.

```python
def tooltip_of(run, *, status, overdue, overdue_days) -> str:
    start = run.start_date or run.end_date
    end = run.end_date or run.start_date
    조각 = [run.department.name if run.department else "담당 없음", status]
    if run.assignee:
        조각.append(run.assignee.name)
    if start:
        조각.append(f"기간 {start.isoformat()} → {end.isoformat()}")
    if overdue and overdue_days:
        조각.append(f"마감에서 {overdue_days}일 경과")
    return " · ".join(x for x in 조각 if x)
```

- 매크로 — `title="{{ dot.tooltip }}"`
- 화면 — `dot.title = p.tooltip` 한 줄
- **`data-department` · `data-assignee` 를 뺐습니다.** 조각을 다시 이을
  이유가 없어졌습니다. 점에 남은 것은 `run` · `overdue` · `start` · `end` 뿐입니다
- `retitle()` 을 통째로 지웠습니다

> **이름을 `title` 이 아니라 `tooltip` 으로 둔 이유** — 달력의 점에서
> `title` 은 이미 **업무 이름**을 뜻합니다(`dot.title` = "봉사팀 개별 미팅").
> 같은 이름을 두 뜻으로 쓰면 `dot_of` 안에서 바로 충돌합니다.

#### (a) 담당자를 바꾸면 툴팁에 옛 사람이 남는가 — **있었습니다**

`retitle` 이 `dot.dataset.assignee` 로 문장을 다시 쓰는데 **그 값을 갱신하는
사람이 아무도 없었습니다.** `onAssignee` 가 등록돼 있지 않았기 때문입니다.
그래서 담당자를 바꾼 뒤 상태나 날짜를 건드리면 그 순간 옛 이름이 다시
찍혔습니다.

고친 방식 — `/board/task/{id}/assignee` 가 생김새를 함께 돌려주고,
달력이 `onAssignee: applyAssignee` 로 새 문장을 받아 넣습니다.

브라우저에서 확인:

```
처음            1 총무M · 완료 · 기간 2026-08-03 → 2026-08-17
담당자 → 점검용  1 총무M · 완료 · 점검용 · 기간 2026-08-03 → 2026-08-17
담당자 → 없음    1 총무M · 완료 · 기간 2026-08-03 → 2026-08-17
```

#### (b) `paint_of` 가 `overdue_days` 를 돌려주는가 — **돌려주고 있었습니다**

버그가 아니었습니다. `paint_of` 는 처음부터 `overdue_days` 를 실어 보냈고
`/status` 응답에도 들어 있었습니다. **없었던 것을 있었다고 적지 않습니다.**

다만 **그 옆에서 다른 것이 새고 있었습니다.** `/status` 응답에는 날짜가
없는데 `reload()` 가 `if (p.start)` 로 갈라서, 없는 것을 "비었다"로 읽고
`data-start`·`data-end` 를 지웠습니다. 상태를 바꾸는 순간 **그 점의 기간
비침이 사라졌습니다.**

```js
if ('start' in p) {          // ← 서버가 날짜를 말해 줬을 때만 손댄다
  if (p.start) { dot.dataset.start = p.start; dot.dataset.end = p.end || p.start; }
  else { delete dot.dataset.start; delete dot.dataset.end; }
}
```

전에는 `applyStatus` 가 `{...view, start: dot.dataset.start, ...}` 로 값을
채워 넣어 이 구멍을 막고 있었는데, 그 우회가 필요 없어졌습니다.

브라우저에서 확인(완료 → 진행중, 마감 2026-08-17):

```
처음        1 총무M · 완료 · 기간 2026-08-03 → 2026-08-17            (start/end 살아 있음)
상태 → 진행중 1 총무M · 진행중 · 기간 2026-08-03 → 2026-08-17 · 마감에서 16일 경과
```

기간도 지연 문구도 남습니다.

### 2단계 — `__unused` 의 낡은 이유

`onAssignee` 를 등록했으므로 목록에서 뺐습니다.

그리고 하나 더 있었습니다 — `onClose` 의 이유가
**"닫을 때도 마찬가지다"** 였는데, 그 "마찬가지"가 가리키던 `onOpen` 이
지난 커밋에서 목록을 떠났습니다. 가리킬 곳이 없는 이유가 남아 있었습니다.
혼자 서도록 다시 썼습니다.

#### 이유가 낡은 것을 잡는 방법 — **절반만 찾았습니다**

두 번 다 같은 모양이었습니다. **정말로 안 쓰던 훅이, 화면이 그 일을 직접
하기 시작하면서 필요해졌는데 목록은 그대로**였습니다.

처음에는 넓게 걸었습니다 — "안 쓴다고 적어 두고 그 주어(`assignee`·
`department` …)를 코드에서 만지면 잡는다". **헛짚었습니다.**

```
board.js: onDepartment 을 안 쓴다고 적어 두고 'department' 를 만지고 있다
  → const key = m.department_key || '__none__';
```

`board.js` 는 부서로 줄을 찾지만 그건 **서버에서 방금 받은 값**이고,
`onDepartment` 를 안 걸고 통째로 다시 그리기로 한 판단은 지금도 맞습니다.

그래서 **실제로 당한 모양**으로 좁혔습니다 — 화면이 그 주어를 `data-*` 에
**캐시해 두고 나중에 다시 읽는 것**. 그때만 갱신해 줄 사람이 필요하고,
그 사람이 바로 그 훅입니다. 서버가 방금 준 값은 낡을 수가 없습니다.

```python
for 캐시 in (f"dataset.{주어}", f"data-{주어}"):
    assert 캐시 not in code, f"{name}: {hook} 을 안 쓴다고 적어 두고 …"
```

**`onOpen` · `onClose` · `afterLayout` · `goTo` · `link` · `openFromUrl` 은
못 잡습니다.** 찾을 주어가 없습니다 — `onOpen` 의 'open' 은 `onlyOpen` 에도
걸립니다. **이 절반은 방법을 찾지 못했고, 없는 것을 있다고 적지 않습니다.**
그 말을 시험의 독스트링에 그대로 남겼습니다.

남은 안전망은 사람이 읽는 것뿐이라, 대신 **이유가 혼자 서게** 만들었습니다 —
"마찬가지" 처럼 다른 항목을 가리키는 말을 금지합니다. 두 번째 사고가
정확히 그 모양이었기 때문입니다.

### 3단계 — 캐시 정책을 코드 안으로

```python
class ImmutableStatic(StaticFiles):
    def file_response(self, *args, **kwargs):
        resp = super().file_response(*args, **kwargs)
        resp.headers["Cache-Control"] = "public, max-age=31536000, immutable"
        return resp
```

코드에 함께 적은 것 — 이것이 통하려면 **주소가 정말 내용에 따라 달라져야
하고**, `?v=` 를 손으로 박으면 1년짜리 옛 파일을 물게 되어 지난번 4시간보다
훨씬 나쁘다는 것. 그리고 **캐시 키에 쿼리가 들어가는지는 Cloudflare
대시보드 설정이고 그 스위치는 이 저장소에 없다**는 것 — `Ignore Query
String` 으로 바뀌면 주소를 `/static/js/calendar.<해시>.js` 처럼 **경로**로
바꿔야 합니다.

#### 서비스 워커·매니페스트

**`static()` 을 지나지 않습니다.** 확인한 사실:

| | 주소 | 어떻게 서빙되나 |
|---|---|---|
| 서비스 워커 | `/sw.js` (`app.js` 에 박힌 고정 문자열) | `main.py` 의 자기 라우트 · `FileResponse` |
| 매니페스트 | `/manifest.webmanifest` (`<link rel=manifest>`) | 같음 |

둘 다 `/static` **밖**이라 `immutable` 도 붙지 않습니다. 옮기면 배포마다
서비스워커가 새로 등록되고 옛 등록이 남으며, 매니페스트 주소가 바뀌면 홈
화면에 추가한 앱이 다른 앱으로 읽힙니다 — 그 말을 그 자리에 적어 두었습니다.

## 7. 판단이 들어간 자리 (발췌)

### `onAssignee` 에 응답 전부를 넘긴 것

`drawer.js` 는 이름만 넘기고 있었습니다(`call('onAssignee', runId, saved.assignee)`).
달력은 서버가 만든 문장이 필요하고 보드는 지금처럼 이름만 씁니다. 그래서
**세 번째 인자로 응답 전부**를 덧붙였습니다 — 보드의 `applyAssignee(runId, name)`
은 고치지 않아도 그대로 돕니다.

```js
call('onAssignee', d.run_id, saved.assignee, saved);
```

### `/assignee` 가 생김새까지 내는 것

담당자는 점에 **적히지 않습니다.** 그런데 툴팁에는 들어갑니다. 그래서
"생김새가 안 바뀌는 요청" 처럼 보이지만 실제로는 바뀝니다 — 그 어긋남이
