# 3. 아이폰 사파리 — 코드에서 먼저 막았습니다 (지시 2)

## 3-1. 코드를 읽어 가른 것 (지시 2-a)

닫는 길은 `sidenav.js` 에 **셋**입니다.

| 닫는 길 | 무엇이 부르나 | 아이폰에서 |
|---|---|---|
| 토글을 다시 누름 | 단추의 `click` | **간다** — 단추는 원래 클릭을 내는 것입니다 |
| 사이드바 링크로 화면을 옮김 | 링크 이동 | **간다** |
| **바깥을 누름** | `document` 의 `click` | **안 갈 수 있습니다** |

사파리는 누른 것이 **누를 수 있는 것처럼 보일 때만**(링크·단추·`role`·
`cursor:pointer`) 합성 클릭을 `document` 까지 올립니다. 본문의 빈 자리는 그
어느 것도 아니라, 그 줄이 아예 안 불릴 수 있습니다.

## 3-2. 무엇을 왜 넣었나 (지시 2-b)

```css
@media (hover:none){body{cursor:pointer}}
```

**손가락 기기에만** 겁니다. 처음에는 `hover:none` 하나로 걸었는데, 그것은
「주 입력기에 호버가 없다」 이지 「마우스가 없다」 가 아닙니다 — **터치가 주
입력기인 노트북에 마우스를 꽂으면 화면 전체가 손 모양**이 됩니다. 검토가
짚어 `and (pointer:coarse)` 로 좁혔고, 아이폰은 둘 다 참이라 그대로 잡힙니다.

**재는 조건도 같이 옮겼습니다** — `phone.js` 가 CSS 와 **같은 미디어 쿼리**로
가릅니다. 갈라 두면 「걸어 두고 한 번도 안 재는 창」 이 생깁니다.

**`pointerdown` 으로 듣는 쪽은 안 골랐습니다.** 그러면 닫는 때가 앞당겨져
**바깥을 눌러 닫는 그 누름이 본문의 링크까지 눌러 버립니다** — 닫으려던
사람이 엉뚱한 화면으로 갑니다. 가림막(스크림)을 두는 길도 있지만 화면이
달라지고 phone.js 의 「본문의 링크가 눌리는 자리에 있다」 와 부딪힙니다.

**실기로 재지 않았습니다.** 아이폰이 없습니다 — 이 줄은 **코드에서 먼저 막은
것**이고, 맞는지는 사람이 봐야 닫힙니다. 봐둘것 AY-c 에 같은 말을 적었습니다.

## 3-3. 아이폰에서 볼 것 한 줄 (지시 2-c)

`docs/인계.md` 18번(사역자 계정)에 넣었습니다 — 첫 로그인 때 총무팀이 부탁할

## 3-4. 흉내로 잰 것과 못 잰 것 (지시 2-d)

| | 어디까지 |
|---|---|
| **잰 것** | 390px 로 두면 그 창이 실제로 `(hover:none) and (pointer:coarse)` 가 되고(재서 확인), 그때 본문의 커서가 `pointer` 인가 — `phone.js` 의 새 항목이 그것을 봅니다. 고장(`body{cursor:auto}`)을 심어 ✗ 가 나는 것까지 봤습니다(갈래 ⑧) |

움직였는지를 한 번도 안 봤고**, 그러면 남는 줄(「B 가 안 움직였다」)은 A 가
애초에 안 움직여도 초록입니다. 검토자가 `reschedule` 을 통째로 no-op 으로
바꿔 치고 돌려 **1 passed** 인 것을 보여 줬습니다.

「A 는 움직였다」 를 세우는 줄로 바꿨고, **같은 고장을 다시 심어 이제
1 failed 인 것**을 봤습니다. 11-3 이 「센 것이 0이면 성공이 아니라 실패」 라고
적어 둔 그 모양이고, **이 판에서 가장 비싼 지적**이었습니다 — 그대로 나갔으면
「새는 곳이 없다」 의 근거가 빈 줄이 될 뻔했습니다.

같은 자리에서 뜻 없는 줄 하나(`assert B != A`)도 걷었습니다.

## 5-5. 재다가 새는 곳이 나왔나 (지시 5-f)

**안 나왔습니다.** 여덟 줄이 (위의 b03 을 고친 뒤에도) 초록이고, **고친 것은
코드가 아니라 제 시험**이었습니다 — 세션 밖에서 지연 로딩을 읽은 것 ·
`departments_of` 에 회차 객체를 넘긴 것 · `build()` 가 안 내는 열쇠를 본 것 ·
그리고 위의 이빨 빠진 줄.

**그것이 이 판에서 재 볼 수 있었던 전부라는 뜻이 아닙니다** — 이 여덟 줄은
넷의 **대표 자리**이고, 예를 들어 지출·예산·회의록 쪽은 아직 이 눈에 안
들어왔습니다. 다음 판이 넓힐 자리입니다.

**그리고 쓰는 길이 자리마다 다릅니다** — 다섯은 화면이 쓰는 엔드포인트로
고치고(`a01`·`b01`·`b02`·`c01`·`d01`), 셋은 도메인 함수로 고칩니다

# 12. 이 판이 낸 사고 — **운영 DB 를 비웠습니다**

**커밋 전에 멈췄습니다.** 코드·시험·문서는 다 됐지만, 운영이 빈 채로 있는
동안 밀어 넣지 않습니다.

## 12-1. 무엇이 일어났나

`data/app.db` 의 표 서른일곱이 **전부 0행**입니다(파일은 720KB · 스키마만
남았습니다). 마지막 쓰기는 **2026-09-13 00:26:40**.

```
retreats 0 · users 0 · task_runs 0 · meetings 0 · equipment_runs 0
programs 0 · activity_logs 0 · notifications 0
```

## 12-2. 왜 — 시험이 운영 DB 를 잡았습니다

검토자가 심은 고장(`reschedule` 을 no-op 으로)을 제가 재현하면서 이렇게
돌렸습니다.

```
pytest tests/test_stage41.py::test41_b03_… -p _noop_plugin
```

`-p` 로 준 플러그인은 **`conftest.py` 보다 먼저** 읽힙니다. 그 파일이
`import app.domain.library` 를 하는 순간 `app.db` 가 **운영 주소 그대로**
엔진을 만들었고, 뒤이어 `client` 픽스처의 `Base.metadata.drop_all(engine)`
이 그 엔진으로 표를 지웠습니다.

**보호막은 있었고 제가 앞질렀습니다.** `tests/conftest.py` 는 맨 위에서
`DCB_DATABASE_URL` 을 임시 폴더로 바꿔 두는데, 그것은 **「app 을 import 하기
전에 conftest 가 먼저 돈다」 는 순서에만 기대고 있습니다.** 그 순서를 앞지르는
길이 셋 이상 있습니다 — `-p` 플러그인 · `PYTHONSTARTUP` · IDE 플러그인.
**사람이 조심할 때를 정하는 규칙은 그 「때」 가 아닌 날 뚫립니다**(11-3 의
그 문장) — 정확히 그 모양입니다.

## 12-3. 무엇을 잃나

가장 최근 백업은 **`data/backups/app-20260912-151859.db`**(2026-09-12 15:18)
이고, 그 안에는 다 있습니다.

```
회차 2 · 사용자 1 · 업무 208 · 회의록 53 · 비품 188 · 프로그램 61 · 논의 58 · 지출 12
```

**그 뒤 아홉 시간의 운영 기록은 못 돌아옵니다.** 그 사이 화면에서 하신 일이
대체로 읽기였다면 잃는 것이 없고, 체크·입력을 하셨다면 그만큼 잃습니다 —
**이 창은 그것을 알 길이 없습니다.**

**지운 파일은 안 지웠습니다** — `data/backups/비운판-20260913-0050.db` 로 떠
두었습니다. 되돌린 뒤에도 지금 상태로 다시 갈 수 있습니다.

## 12-4. 되돌리는 길

**업로드와 VAPID 는 안 건드립니다** — 지워진 것은 DB 뿐이라, 그 둘까지 옛
날짜로 돌리면 지금 있는 파일을 오히려 잃습니다(11-2 의 「같은 날짜끼리 셋을
함께」 는 **백업에서 통째로 되돌릴 때**의 규칙입니다).

```
powershell -NoProfile -Command "Stop-ScheduledTask -TaskName '대청부 앱'; Get-NetTCPConnection -LocalPort 8000 -State Listen -EA SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }"
Copy-Item -Force "data\backups\app-20260912-151859.db" "data\app.db"
powershell -NoProfile -Command "Start-ScheduledTask -TaskName '대청부 앱'"
```

되돌린 뒤 **행 수를 다시 세어** 백업과 같은지 봅니다(11-2 의 「돌린 뒤 다시
세어 보고에 싣는다」).

## 12-5. 다음 판이 아니라 **되돌리는 그 판에 함께 넣을 것**

- `tests/conftest.py` 가 **자기가 연 DB 가 임시 폴더인지 먼저 보고**, 아니면
  `drop_all` 앞에서 멈춥니다. 순서에 기대지 않고 **매번 도는 검사**로 둡니다
- 봐둘것에 이 사고와 입구(`-p` · `PYTHONSTARTUP` · IDE)를 적습니다
- **고장을 심어 재는 자리는 운영 DB 와 같은 기계에서 돕니다** — 그 판단
  자체를 다시 봐야 합니다(지금은 pytest 가 운영 폴더 옆에서 돕니다)
