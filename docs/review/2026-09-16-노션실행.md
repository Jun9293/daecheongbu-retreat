[고쳐야 함 A] 1c 의 새 범위 문단이 「라이브러리」 줄에 틀리게 걸린다 (물음 3)

       라이브러리와 관련업무는 노션 id 가 달린 것(이번에 선 233) 범위다."

  그런데 표의 줄마다 범위가 다르다. 내가 센 값이다.

      :59  라이브러리              106 → 339    저장소 전체 (전체 339)
      :60  노션 id 가 달린 라이브러리  0 → 233    노션 범위
      :62  관련업무 …(노션 id 달린 것만)  172·394  노션 범위

# 8. 검토 뒤 고침

검토가 짚은 것을 고쳤다. **검토 뒤에 고친 것은 검토를 안 거친 것**이라(11-3) 이 차이만 검토자에게 한 번 더 보이고 그 답도 원문으로 싣는다.
