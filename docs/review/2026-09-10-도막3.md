# 1. 설계표 — `user_departments` 안을 0 의 셈에 비추어

**안 (지시문)** — `user_departments(user_id · department_id · dept_role ∈
{lead, member})` 표를 새로 두고 한 사람이 여러 줄. `users.role` 은
`admin · viewer · 일반` 셋만 남기고 `dept_lead·member` 는 소속에서 파생.
`users.department_id` 는 없앤다. 부서 비교는 key 로. 「내 부서인가」 는
「내 부서 중 하나인가」 로. 설정 › 사용자에서 한 사람에 부서를 여럿 붙이고
각각 리더/팀원.

**정하지 않습니다 — 사람이 정합니다.** 아래는 안을 그대로 놓았을 때
자리마다 무엇이 되는지와 위험입니다. 「위험」 칸은 권한이 **넓어지는**
자리인지 **좁아지는** 자리인지, 또는 **갈리는**(정하지 않으면 두 뜻이
되는) 자리인지입니다.
