# 3. 자가시험이 새 여섯에 심는다 (지시 3)

지난 판이 점검에 항목 여섯을 더하면서 **「떠서 ✓ 가 붙은 것을 본 것이지
심었더니 ✗ 가 난 것을 본 것이 아니다」** 라고 스스로 적었습니다. 그 자리를
닫았습니다.

## 3-1. 넷으로 여섯을 덮습니다 (지시 3-c)

| 심은 고장 | 잡는 항목 |
|---|---|
| ⑬ 줄이 빈다 | 옮긴 자리 줄에 글이 있음 |
| ⑭ 단추가 권한과 반대 | 되돌리기 단추가 있음/없음 (권한) |
| ⑮ 눌러도 기간 칸이 안 따라옴 | 자리 되돌리기 · **되돌리니 기간 칸도 함께 바뀜** |
| ⑯ 왕복해도 안 돌아옴 | 자리 다시 되돌리기 · **왕복하면 원래 자리로** |

**누르는 항목 둘은 따로 못 심습니다.** 「되돌리기」 와 「다시 되돌리기」 는
`누른다` 라서 **단추가 죽으면 ✗ 가 아니라 「못 쟀음」** 이 됩니다 — 그것이
그 갈래의 정의입니다. 그 둘은 **바로 뒤의 잰다**가 잡습니다(⑮·⑯). 세우려면
누르는 자리마다 잰다를 하나씩 더해야 하고, 그러면 같은 것을 두 번 재게
됩니다.

**옮긴 적이 없는 업무를 연 판에서는 못 심습니다** — 그 줄이 아예 안 뜹니다.
그때는 ✗ 가 아니라 **「못 심음」** 이 그쪽의 정답입니다.

## 3-2. 심었더니 처음에는 **넷 다 통과로 지나갔습니다**

```
⑬ 끈 자리 — 줄이 빈다 → 통과로 지나감 — 검사가 새는 입구다
⑭ 끈 자리 — 단추가 권한과 반대 → 통과로 지나감 — 검사가 새는 입구다
⑮ 끈 자리 — 눌러도 기간 칸이 안 따라옴 → 통과로 지나감 — 검사가 새는 입구다
⑯ 끈 자리 — 왕복해도 안 돌아옴 → 통과로 지나감 — 검사가 새는 입구다
```

**심을 때 손본 것이 드로어가 열리는 순간 지워졌습니다.** 그 줄은
`renderMoved` 가 `innerHTML` 로 다시 쓰는데, 심기는 **드로어가 열리기 전**에
돕니다. 그래서 **다시 그려도 살아남게** 고쳤습니다 — 줄을 지켜보다가 다시
쓸 때마다 손봅니다(`줄을지켜본다`), 값은 짧은 되풀이로 붙듭니다
(`값을붙든다` — 값이 바뀌는 것은 DOM 변경이 아니라 지켜보기로 못 잡습니다).

**이것 자체가 자가시험이 한 일입니다** — 심어 보지 않았으면 그 여섯은
「✓ 가 붙으니 잰 것」 으로 남았을 텐데, 실은 **고장을 심어도 ✓ 였습니다.**

## 3-3. 고친 뒤 — **넷 다 ✗ 로 잡고, 안 심으면 ✓** (수용 기준 다)

**같은 판에서 봤습니다** — 자가시험은 심기 **전에 깨끗한 판**을 먼저 돌리고
✗ 가 하나라도 있으면 심지 않고 멈춥니다.

```
깨끗한 판 (관리자 · 보드)   85항목 / 건너뜀 2 / 못쟀음 0 / 실패 0
⑬ 끈 자리 — 줄이 빈다                 → ✗ — 잡음
⑭ 끈 자리 — 단추가 권한과 반대        → ✗ — 잡음
⑮ 끈 자리 — 눌러도 기간 칸이 안 따라옴 → ✗ — 잡음
⑯ 끈 자리 — 왕복해도 안 돌아옴        → ✗ — 잡음
```

# 4. 「마감일만 고쳐도 옮김」 이 수를 부풀리는지 (지시 4)

## 4-1. 같은 수에 들어가고 있었습니다 (지시 4-b)

드로어에서 **마감일만 고쳐도** 같은 엔드포인트로 들어오므로(4-6) 그것도
「손으로 정한 자리」 가 되고, 그때 며칠은 **0** 입니다. 그런데 미리보기는
「손으로 옮긴 적이 있는가」 로만 갈라서 **자리를 민 것과 길이만 다른 것이
한 수**에 들어갔습니다.

## 4-2. 가를 수 있었고 갈랐습니다 (지시 4-c)

`library.어느쪽` 이 셋으로 가릅니다.

| 갈래 | 무엇 |
|---|---|
| `밀기` | 며칠이 0 이 아니다 — **자리가 실제로 밀린다** |
| `기간만` | 며칠은 0 인데 길이가 라이브러리와 다르다 — **자리는 그대로고 늘려 둔 기간만 지켜진다** |
| `다시셈` | 손 자리를 안 따르거나, **따라도 결과가 라이브러리 셈과 같다** — 기본 자리로 되돌려 둔 run 이 여기다. 손 자리에서 **남는 것이 없다** |

**셋째가 있는 것이 이 재기에서 나온 것입니다.** 며칠이 0 이고 길이도 같으면
「손으로 옮긴 자리 그대로 밀 업무」 라고 적혀도 **밀 것이 하나도 없습니다.**

화면은 **「기간만」 이 0 이면 안 냅니다** — 대부분 0 이라 늘 내면 줄이
길어지고, 길어진 줄에서는 정작 봐야 할 수가 묻힙니다(4-15 의 그 판단).

## 4-3. 얼마나 부풀었나 (수용 기준 라)

`test39_c02` 가 **자료를 세어 기대값을 만듭니다** — 수를 시험에 박지
않았습니다. 갈래를 도로 합쳐 심어 보니:

```
가르기 전 → 「자리를 민 업무」 2건
실제로 민 것 →                1건
```

**한 건이 부풀어 있었습니다** — 그 하나가 마감일만 고친 업무입니다.
합성 자료 넷 중 셋이 켜져 있고 그중 둘을 손으로 정한 판에서 잰 값이라,
**비율이 아니라 「갈리는가」 가 이 재기의 답**입니다.

**고치는 것은 사람이 정합니다** — 이 판은 수를 갈랐을 뿐, **마감일만 고친
것을 「옮김」 으로 남길지**는 그대로 두었습니다. 안 남기면 늘려 둔 기간이
개회일이 바뀔 때 조용히 되돌아갑니다(지난 판이 그래서 남기기로 했습니다).
