# 3. 잰 것 — **고치기 전 코드와 같은 자료로 견줬다**

지시가 「고치기 전 코드로는 그 시험이 실패하는지 한 번 확인하고 보고에 적으라」 고 했다.
스크립트를 임시 폴더에 복사해 그 두 줄만 옛 모양으로 되돌리고, **같은 합성 TSV** 로
둘을 돌렸다.

자료: 메모 1줄 → 같은 자국 줄 두 벌(2·3행) → 머리글(4행) → 멀쩡한 줄 둘(5·6행) →
**자국 줄(7행)**. 멈춰야 하는 자리는 7행이다.

```
고치기 전 → 품목 이름에 사람 자국이 있습니다 (시트의 2번째 줄) — …
고친 뒤  → 품목 이름에 사람 자국이 있습니다 (시트의 7행) — …
```

`test31_a01` 은 「시트의 7행」 을 찾으므로 **고치기 전 코드로는 빨갛다.** 옛 코드가
가리킨 2행은 머리글 **위**의 메모 구역이라, 사람이 열면 아무것도 없다 — 오늘 실제로
일어난 일이 이것이다.

되돌린 사본은 임시 폴더에만 만들었고 저장소에는 없다.

# 4. 사람이 돌릴 명령 — **운영 DB 는 이 판에서 안 건드렸다**

이 판은 운영을 **읽기만** 했다(`sqlite3.connect(..., mode=ro)`). 읽어서 확인한 것:

| 물은 것 | 답 |
|---|---|
| 열려 있는 회차 | 둘 (id 1 `2026 여름수련회 Belong` · id 2 `2027 여름수련회`) — **그래서 이제 `--회차` 가 필수다** |
| 부서 | 두 회차 **각각 아홉** — 화면이 「없습니다」 라고 한 것이 거짓이었음이 여기서 확인된다 |
| 비품 run | 회차 1 에 58 (총무 30 · 헤브론 8 · 코람데오 20). 회차 2 에 **0** — 사람이 되돌린 것이 그대로다 |
| 코람데오 28줄 | 회차 1 에 들어가 있다 (헤브론 8 + 코람데오 20) |

**총무 시트를 넣는 명령** — 그 시트는 지금 멈춘다. 품목 이름에 사람 이름이 붙은 줄이
있다. **어느 줄인지는 아래 미리보기가 「시트의 N행」 으로 말해 준다** — 그 행을 시트에서
고친 뒤 다시 돌린다. `--회차 1` 을 꼭 붙인다.

```
.venv\Scripts\python.exe scripts/비품들여오기.py 총무 data/비품-총무.real.tsv --회차 1
```

멈추면 이제 **「시트의 N행」** 으로 말한다 — 그 행을 그대로 열면 된다. 미리보기가
맞으면 `--실행` 을 붙여 다시 돌린다.

```
.venv\Scripts\python.exe scripts/비품들여오기.py 총무 data/비품-총무.real.tsv --회차 1 --실행
```

**`--회차` 를 빼면 이제 멈추고** 이렇게 낸다 — 넣기 전에 한 번 그대로 돌려 보시면
바뀐 것이 보인다.

```
!! 열려 있는 회차가 2개라 어디에 넣을지 알 수 없습니다 — --회차 <id> 로 골라 주세요.
    --회차 2   2027 여름수련회
    --회차 1   2026 여름수련회 Belong
```

**관리자가 못 들어가게 됐을 때** (오늘 겪은 그 자리 · 새로 만든 것이 아니라 있던 것):

```
.venv\Scripts\python.exe scripts/관리자링크.py
.venv\Scripts\python.exe scripts/관리자링크.py <id>
```

링크는 **그 창에만** 뜬다. 파일로 안 남고 다시 보여줄 수도 없다(토큰 원문을 저장하지
않는다 — 4-12). 창을 닫았으면 다시 발급한다.

**고르는 열쇠가 다르다**: 그것은 관리자 목록을 먼저 찍고 **id** 로 고른다. 그 파일

못 하면** 번호로 찾는 길은 막힌다. 목록을 먼저 보이는 쪽이 오늘 같은 상황에 더
맞다고 보아 **그대로 두었다.** 번호로도 찾고 싶으시면 한 줄이면 되지만, 그러면
`관리자링크.py 3` 의 `3` 이 id 인지 번호 뒷자리인지 갈려서 **고르는 열쇠가 둘**이
된다 — 그 값을 어느 쪽으로 읽을지 사람이 매번 정하게 된다. 여쭙니다.
