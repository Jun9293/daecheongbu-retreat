## 0-b. 잔액 카드

`app/domain/budget.py` 의 `BudgetSummary.balance` = `total_income − total_planned`
(111~113줄). 수입 행이 0 이면 `total_income` 이 0 이라 **−(지출예산 총액)** 이 나옵니다 —

## 0-c. 봉사팀 표의 셀 종류와 받는 쪽

`app/domain/staff_sheet.py` 의 `build()` 가 내는 `cells` 의 `kind`:

| kind | 무엇 | 운영 회차 1 |
|---|---|---:|
| `head` | 「시각」 둘 · 날짜 머리(일자마다 병합) · 「봉사자」/「전체일정」 띠 머리 | 13 |

| `body` | 봉사자·전체일정 내용 (rowspan·colspan 병합) | 57 |
| `empty` | 내용 없는 칸 — 시각 단위(2×2)로 병합, 반 칸만 비면 한 줄씩 | 14 |
| `note` | 개회일 전체일정의 「참가자 등록 전」 | 1 |
| 합 | 병합(rowspan>1 또는 colspan>1) 123 · `dense` 5 | **125** |

열은 시각 · (일자마다 봉사자 띠 2열, 전체일정이 있으면 2열 더) · 시각 = 16열, 42줄.
`fill` 은 구조에 실린 파일용 색 — D9EAD3(전체일정) 32 · FFF2CC(봉사자) 20 ·
CFE2F3/FCE5CD(파트) 12 · D9D9D9(머리) 6 · 없음 55.

- **화면** — `app/templates/staff_sheet.html` 이 `cells` 를 `<th>/<td class="c-{kind}">` 로
  놓고 `style="background:#{fill}"` 로 파스텔을 그대로 칠했습니다. CSS 는
  `app/static/css/retreat.css` 의 `.sheetwrap`~`.ssheet` 블록(1288~1350줄) —
  시각 열 `--mono`, 격자 `rgba(0,0,0,.55)`, 일자 경계 `3px double`.
- **엑셀** — `app/domain/staff_xlsx.py` 의 `write()` 가 같은 `cells` 를 놓습니다.
  글꼴은 그 파일의 `FONT = "맑은 고딕"` · 크기는 `sheet["font"]`(staff_sheet 가
  실어 보냄), 색은 `cell["fill"]`(**staff_sheet.py 의 `FILL_*` · `TEAM_PART_FILLS`**)
  → 색은 표 함수에, 글꼴은 xlsx 쪽에 묶여 있습니다.

# 8. 판단이 들어간 자리

1. **0-d 는 표 함수에서 고쳤습니다** — 3-a 가 허락한 그 경우입니다. 화면만 CSS 로 선을
   지우면 파일은 그대로 갈라져 「어긋난 쪽이 파일」 이 됩니다(5-8).
2. **파트를 `fill` 에서 되돌립니다** — 구조에 `part` 를 더하면 표 함수를 고치는 것이라,
   같은 함수(`fill_for_part`)의 역함수를 라우터가 만듭니다. 파스텔 상수가 파트마다
   다르다는 전제 위에 있습니다(`test_08b` 가 그것을 잽니다).

   남습니다. 3px 차이는 `overflow:hidden` 안이고, 상수를 바꾸면 dense 판정이 달라져
   파일 글자 크기가 바뀝니다 — 그건 3-a 밖입니다.

5. **수입 표의 잔액 줄도 「수입 미입력」** — 지시는 카드만 말했지만 같은 화면에 같은 음수가
