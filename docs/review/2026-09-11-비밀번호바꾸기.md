# 1. 비밀번호를 바꾸는 자리 (지시 1)

## 1-1. 어디에 무엇이 생겼나

| 자리 | 파일 |
|---|---|
| 판정 · 기록에 남길 이름과 문장 | `app/domain/login.py` 의 `바꿔도되나` · `바꾼_행위` · `바꾼_말` |
| 설정 › 내 정보의 그 칸 | `app/templates/settings.html` — `{% if can_change_password %}` 안 |
| 받는 곳 | `app/routers/settings.py` 의 `change_my_password` (`POST /settings/password`) |
| 첫 비밀번호를 바꾸는 화면 | `app/routers/login.py` 의 `password_submit` — **같은 판정을 부르도록 고쳤습니다** |

**`/password` 는 원래 자기 자리에서 길이와 같음을 직접 봤습니다.** 그 두 줄을
걷고 `바꿔도되나` 를 부릅니다 — 남겨 두면 규칙이 두 벌이 되고, 한쪽만 고쳐진
날 **어느 화면에서 통과하느냐가 갈립니다.**

## 1-2. 지금 비밀번호를 안 묻습니다 — 무엇이 남나

사람이 정한 것이라 뒤집지 않았습니다. **남는 것을 적습니다** (봐둘것 AS-a).

- 잠그지 않은 브라우저를 잠깐 빌려준 사이에 **그 자리에서 계정을 가져갈 수
  있습니다.** 새 값을 두 번 적으면 끝이고, 옛 값은 그 순간 죽으므로 원래
  주인이 못 들어옵니다
- **그 창이 넓은 까닭은 세션이 길어서입니다**(4-12). 한 번 들어온 기기는
  오래 들어온 채로 있습니다 — 며칠인지는 `config.SESSION_DAYS` 한 곳이라
  여기 안 적습니다
- **반대 방향도 남습니다 — 바꿔도 이미 들어와 있는 기기는 안 죽습니다.**
  해시만 바뀌고 세션 쿠키는 그대로입니다. 「누가 내 계정을 쓰는 것 같다」 는
  사람이 비밀번호를 바꿔도 **쫓아내지 못합니다.** 검토가 짚어 AS-a 와 화면
  안내에 적었습니다 — 전에는 화면이 「다른 기기에서 다음에 들어올 때부터」 라고
  적어 **「다른 기기가 잠긴다」 로 읽힐 수 있었습니다**

**막는 대신 말합니다** — 그 칸 아래와 `docs/로그인-안내문.md` 둘 다에
「남의 기기에서 쓰셨으면 끝나고 로그아웃해 주세요」 가 있습니다.

## 1-3. 비밀번호가 없는 계정에는 안 보입니다

첫 비밀번호를 아직 안 받은 사람에게는 바꿀 것이 없고, 그 사람이 할 일은
총무팀에서 받는 것입니다. **화면만 감춘 것이 아니라 서버도 같은 판정으로
막고**, 막으면서 무엇을 해야 하는지 말합니다.

## 1-4. 375px 에서 실제로 열어 잰 값 (지시 1-e)

**개발 서버(8001)를 375×812 로 열어 쟀습니다.** 로그인 → 설정 → 그 칸을
실제로 채워 바꿔 봤습니다. 아래는 `getBoundingClientRect` 와
`getComputedStyle` 로 그 화면에서 읽은 값입니다.

| 잰 것 | 값 |
|---|---|
| 창 | 375 × 812 (devicePixelRatio 2) |
| `#mypw` · `#mypw2` | **글자 16px** · 폭 314.0 · 높이 47.7 · 안쪽 여백 10px 12px |
| `바꾸기` 단추 | 글자 16px · 폭 314.0 · 높이 49.7 |
| 라벨 | 13px |
| 칸이 든 카드 | 폭 347.3 |
| 가로로 넘치나 | **안 넘칩니다** — `scrollWidth` 375 = `clientWidth` 375 |

**`input[type=password]` 규칙이 이 화면에도 걸립니다.** 그 칸에 실제로 걸린
규칙을 브라우저에서 뽑아 보니 **둘**이고 둘 다 같은 값을 줍니다.

```
input[type="password"]                { font-size: var(--fz-lg); padding: 10px 12px; ... }
.loginform input[type="text"],
.loginform input[type="password"]     { width: 100%; box-sizing: border-box; font-size: var(--fz-lg); ... }
```

`--fz-lg` 는 16px 이므로 **아이폰이 확대하지 않습니다**(4-0 · 7번 지시의 그
경계). 높이 47.7px 는 5-0 의 44px 기준 위입니다 — 그 기준은 현장 화면의
것이지만 휴대폰에서 누르는 칸이라 같이 적어 둡니다.

## 1-5. 넓은 화면에서도 한 번 열었습니다 (검토가 짚어서)

**1-4 는 375px 만 쟀는데, 그 폭에서는 칸이 한 열이라 안 보이는 것이
있었습니다.** 검토가 짚어 1440×900 에서 다시 열어 쟀습니다.

| 같은 카드 안 | 글자 | 크기 | 클래스 |
|---|---|---|---|
| 바로 위 「저장」(이름·연락처) | 13px | 44.5 × 31.4 | `sbtn p` |
| 새로 만든 **「바꾸기」** | **16px** | **535 × 50.4** | (없음 — `.loginform button`) |

**같은 페이지에 단추 어휘가 둘이 됐습니다.** `class="loginform"` 을 로그인
화면에서 그대로 가져왔기 때문입니다 — 그 클래스가 세로 flex 라 단추가 카드
폭을 꽉 채웁니다. 가로로 안 넘칩니다(1440/1440)만, 작은 알약 옆에 남색 막대가
섭니다. **고치지 않고 「정할 것」 에 올렸습니다**(9장) — 어느 쪽이 맞는지는

**안내 줄은 12px 입니다**(`.fld .hint` — 이 판이 만든 클래스가 아니라 그
페이지가 원래 쓰던 것). 4-0 은 혼자 뜻을 지는 글자에 14px 을 두는데, 지금
「남의 기기에서 쓰셨으면 로그아웃해 주세요」 가 거기 있습니다 — **안 묻기로
한 대가를 감당하는 문장 전부가 장식 단에 놓여 있는 셈**입니다. 이것도
「정할 것」 에 올렸습니다.

# 6. 돌고 있는 서버에서 확인한 것

**재시작했습니다 — 이번 커밋에 `app/` 과 `templates/` 가 들어 있으므로
건너뛰지 않았습니다** (11-3 2단계 · 배포-안내 12-1).

```
멈추기 전 PID: 18516
포트가 비었습니다
다시 켠 뒤 PID: 12048
성공 — PID 가 바뀌었습니다
```

**올라온 뒤 실제로 받아 봤습니다.** 이번 판이 만든 것은 **로그인해야 보이는
화면**이라, 운영 계정으로 들어가지 않고 볼 수 있는 것을 골랐습니다 —
**그 자리가 서버에 실제로 생겼는가**입니다.

| 물은 것 | 답 | 무엇을 말하나 |
|---|---|---|
| `GET /login` | 200 | 서버가 살아 있습니다 |
| `POST /settings/password` | **303 → `/login`** | **그 길이 있습니다** — 로그인을 요구하는 것이지 없는 주소가 아닙니다 |
| `POST /settings/passwordXYZ` | **404** | **없는 주소는 404 로 옵니다** — 위의 303 이 「무엇이든 303」 이 아니라는 증거 |
| `GET /settings` | 303 → `/login` | |

**둘째 줄만으로는 부족합니다.** 이 앱은 로그인 안 한 요청을 전부 `/login` 으로
보내므로, **없는 주소도 303 으로 오는지**를 함께 봐야 그 303 이 뜻을 가집니다.
셋째 줄이 그것을 잽니다 — 404 로 오므로 둘째 줄의 303 은 **그 라우터가 실제로
붙어 있다**는 뜻입니다.

## 검토 뒤에 한 번 더 재시작했습니다

검토가 짚은 화면 문구([봐3])를 고치면서 `app/templates/settings.html` 이 또
바뀌었습니다. **그 커밋에 `templates/` 가 들어 있으므로 또 건너뛰지
않습니다** — 11-3 은 「커밋 기준으로 봅니다. 그 커밋을 여는 사람은 판을
모릅니다」 라고 적어 두었습니다.

```
멈추기 전 PID: 12048
포트가 비었습니다
다시 켠 뒤 PID: 26668
성공 — PID 가 바뀌었습니다
```

세 줄을 다시 물었고 답이 같습니다 — `GET /login` 200 ·
`POST /settings/password` 303 → `/login` · `POST /settings/passwordXYZ` 404.

> **운영 계정으로 들어가 화면을 보지는 않았습니다.** 그러려면 운영 비밀번호가
> 필요하고, 그것은 11-2 의 「사람만 쥘 수 있는 값」 입니다. 화면 자체는 개발
> 서버에서 375px 로 열어 값을 재고 실제로 바꿔 봤습니다(1-4).

## 라) 를 낱말로 재지 않은 까닭

「두 화면이 같은 함수를 부르는가」 를 **글자 찾기**로 재면, 그 시험의
독스트링과 주석이 그 이름을 담고 있어서 **고쳐 놓고도 초록**입니다(10장의
그 함정 — 지금까지 다섯 번). 그래서 `ast` 로 파일을 읽어 **`Call` 노드의
속성 이름만** 모아 견줍니다.

**그리고 그 시험이 실제로 무는지 확인했습니다.** 심은 것은 이 두 줄입니다 —
`settings.py` 의 `바꿔도되나` 호출 세 줄을 빼고 그 자리에 넣었습니다.

```python
    if 로그인.너무짧나(password):
        return redirect("/settings", message="짧습니다.")
```

`d01` 과 `b01` 이 **함께** 빨개졌습니다 — `d01` 은 호출이 사라져서,
`b01` 은 「두 번 적은 값이 다름」 을 보는 줄이 함께 사라져 그 값이 통과하는
바람에 ③ 이 걸려서입니다(`redirect` 는 그 파일에 있는 이름이라 터진 것이
아닙니다 — 검토가 그 가능성을 물어 여기 적습니다). 되돌린 뒤 다시 초록입니다.

## 그런데 `d01` 만으로는 모자랐습니다 — 검토가 구멍을 찾았습니다

검토자가 변이를 넷 심어 봤고 **하나가 빠져나갔습니다** — 「호출은 그대로 두고
**한쪽 화면에만 다른 축의 규칙을 하나 더**」(이를테면 「숫자만이면 거절」).
호출이 그대로라 `d01` 이 지나가고, 길이 규칙이 아니라 `b01` 도 안 걸립니다.

`d01` 이 실제로 재는 것은 **「둘 다 그 함수를 부른다」** 이지
**「그 함수 말고는 안 가른다」** 가 아닙니다. 수용 기준 라) 의 글자는
채웠지만 제목(「판정이 한 곳이다」)까지는 못 잽니다.

**그래서 `test35_d02` 를 더했습니다** — 같은 값 한 벌(규칙 안 · 숫자만 ·
딱 경계 · 한 글자 모자람 · 두 번 적은 값이 다름 · 빈 값)을 **두 화면에 각각
먹여 받아들임과 거절이 같은지** 봅니다. 다 거절하거나 다 받아들이면 그
비교가 공짜로 참이 되므로 **둘 다 있었는지도 함께** 봅니다.

**그 변이를 실제로 심어 봤습니다** — `settings.py` 에만
`if password.isdigit(): return redirect(...)` 를 넣으니 `d02` 가
「① 두 화면이 갈렸다: '12345678901234'」 로 빨개졌고 `d01` 은 초록이었습니다.
검토자가 말한 그대로입니다. 되돌린 뒤 아홉 판 전부 초록입니다.

**곁가지 하나** — `b01` 의 ④(「규칙 안 값이 지나간다」)가 걸리는 것은 새값이
마침 규칙 안이라서였습니다. 다음 사람이 그 값을 짧게 바꾸면 그 줄이 조용히
죽으므로 `assert not 로그인.너무짧나(새값)` 한 줄을 앞에 뒀습니다.

# 9. 판단이 갈린 자리와 사람이 정할 것

1. **`/password` 의 두 줄을 걷고 부르게 한 것.** 남겨 두고 「같은 값을 본다」
   고 적을 수도 있었지만, 그러면 라] 를 **손으로 적은 목록**과 견주게 됩니다 —
   지시가 명시적으로 금지한 모양입니다
2. **`/settings/password` 가 `user.password_hash` 를 서버에서 다시 본 것.**
   화면이 이미 감추므로 없어도 됩니다. 두는 까닭은 **화면만 감춘 것과 막은
   것은 다르기 때문**이고, 다] 가 그 둘을 갈라 재라고 했습니다
3. **사역자 계정을 안 만든 것.** 지시가 「만들지는 않는다」 였고, 실명이
   오가는 자리입니다(11-2). 대신 **가명 열 명으로 실제로 해 봤습니다**
4. **담당자 고르는 자리를 안 고친 것.** 지시가 「고치는 것은 이 판이
   아니다」 라고 못박았습니다. 잰 값과 고칠 때 볼 곳만 AU-a 에

5. **넓은 화면의 단추 어휘를 안 맞춘 것.** 검토가 짚었고 잰 값은 1-5 에
   있습니다. 고치는 것이 한 줄이지만 **어느 쪽이 맞는지는 눈으로 볼 일**이라
   「정할 것」 으로 올렸습니다
