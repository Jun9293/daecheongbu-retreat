#   낱말 | 왜 넘기는가
#
# **이름이 아니라 낱말을 적습니다.** 이름을 통째로 넘기면 회의록에서
# 홀로 선 그 이름도 안 걸립니다 — 지키려던 바로 그것이 빠집니다.
#
# **한 글자 이름은 홀로 섰을 때만 봅니다.** 낱말 안에 든 것은
# `anonymize.py` 의 경계 규칙에 맡깁니다. 그러지 않으면 이 목록이
# 낱말 수만큼 늘어나고, 늘어난 목록은 아무도 읽지 않습니다 (4-11).
#
# **`[사람]` 이 붙은 줄이 자동 분류가 틀린 자리입니다.** 쌓이면 분류
# 규칙을 어디부터 고칠지 알려 줍니다 — 성적표의 「X 이유를 셀 자리」와
# 같은 자리입니다. 세지 않으면 무엇을 먼저 고칠지가 인상으로 정해집니다.
