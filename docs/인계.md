# 대청부 수련회 시스템 — 미결 목록 (새 채팅이 먼저 읽는다)

갱신: 2026-10-25 **문서 한 줄 정정 — 손 백업은 차례 4 · 5 앞 둘 다**.
`docs/맥-이전.md` 8-8 「차례 앞 확인」 다섯째를 「차례 4 · 5 앞에서 손 백업 한 판 더」 로 고쳤고 차례 5 의 「앞에」 줄도 다섯 줄로 맞췄다(사람이 정함 — 전원 뽑기는 정상 종료가 아니라 자료가 가장 위험하고 백업은 1초). 원본의 「차례 4 앞에서」 는 표현 탓이었다. 12-26 의 「남은 물음」 은 「닫힘: 4 · 5 둘 다」 가 됐고 표에서 그 물음 줄을 내렸다.
서버가 읽는 것이 안 바뀌어 재시작은 없었다.

**남은 단계는 없다 — 다섯이 다 섰고 5단계도 2026-09-27 판으로 닫혔다.** 다음 판이 이어받는 것은 단계가 아니라 아래 표다. **다만 BK-b 는 열려 있다** — 개발에 API 키가 없어 **캡처 읽기를 실제로 눌러 본 적이 없다.** 사람이 운영에서 한 장 올려 봐야 「모델이 실제 은행 캡처를 얼마나 읽어 내는가」 를 안다.

**「남은 것」 표에는 다음 판이 이어받아야 할 것만 올린다** (2026-09-24 사람이 정함) —
못 한 것 · 사람 손이 필요한 것 · 정할 것. **봐 둘 것 후보는 `docs/봐둘것.md` 에만**
적는다: 둘을 섞으면 이 표가 길어져 정작 이어받을 것이 묻힌다.
