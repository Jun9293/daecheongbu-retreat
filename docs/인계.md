# 대청부 수련회 시스템 — 미결 목록 (새 채팅이 먼저 읽는다)

갱신: 2026-09-25 **3단계 판 (보드 — 목업 D · F)**.
**보드를 목업 D 로 다시 그렸다.** 구간이 다섯이 됐고(기획 · 준비 · D-2주 · 수련회 · **후속**), **후속 칸**이 새로 붙었다 — 결산·환급·정리가 그전에는 **축 밖이라 보드에 설 자리가 없었다.** 오늘 칸 강조 · 오늘 세로선 · 「오늘」 단추도 새로 들어왔다(그전에는 보드에 오늘 표시가 **하나도 없었다**).
**하위가 있는 Main 이 기본 접힘이 됐다** — 접히면 하위 바가 Main 아래 한 줄에 눕고, 시작·끝 칸이 같은 하위끼리는 **바 하나로 합친다.** 합친 바는 `data-run` 이 없어 **구조로** 끌 수 없다. 펼침은 기기에 남는다.
**날짜 없는 업무가 개회일 자리에 서던 것을 고쳤다**(봐둘것 BJ-d 를 닫음) — 이제 점선 표시다. **업무 팝업(F)** 도 새로 만들었고 보드·달력이 같이 쓸 한 부품이다(`app/static/js/taskpop.js`).
**BJ-e 도 닫았다** — `create_run` 에 `start = start or end` 를 대칭으로 두어 한쪽만 골라도 그 날 하루가 된다. 활동 기록이 *화면이 보낸 값*으로 적던 것도 **선 run 에서 읽게** 고쳤다.

**보드의 「날짜 없음」 은 넓은 폭과 좁은 폭 둘 다 고쳤다** — 커밋 전 검토가 「BJ-d 가 `make_row` 와 `_by_week` 둘을 적어 뒀는데 앞엣것만 고치고 닫았다고 적었다」 고 짚었다. 좁은 폭 목록에도 **날짜 없는 묶음**이 따로 선다.
**마법사의 날짜 칸은 전과 같다**(`after_weeks=0`) — 보드의 축이 뒤로 늘어난 것이 거기까지 따라오면 「수련회 기간 · 8/30」 이라는 거짓 이름의 칸이 생겼다. **폐회 뒤 주에 업무를 놓게 할지는 봐둘것 BJ-g** 로 올렸다(라이브러리의 상대 위치가 D-주차 하나라 저장할 자리부터 정해야 한다).

**3단계는 닫혔다. 남은 단계는 4(달력 — 목업 E) · 5(마무리)다.** 그때 `tooltip_of` 와 F 팝업이 겹치는 것을 함께 정한다(4-13 이 적어 둔 그 자리) — 지금은 점에 툴팁이 붙어 있고 팝업도 같은 것을 말한다. 앞 판 보고는 `docs/review/2026-09-25-2단계뒷정리.md` 로 얼렸다.
