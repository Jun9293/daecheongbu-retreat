# 대청부 수련회 시스템 — 미결 목록 (새 채팅이 먼저 읽는다)

갱신: 2026-10-25 **맥 이전 문서 갱신 — 두 번째 재시동 · 10/19 읽기 확인 · cloudflared 판 정정**.
`docs/맥-이전.md` 에 12-23(10/07 계획한 재부팅 뒤 스스로 섬) · 12-24(출국 중 macOS 자동 설치를 끔)가 이미 있었고, 이 판이 **12-25** 를 더했다 — **10/11 14:11 재시동**(mtask 쪽 요청)에서 app · tunnel · logrotate 가 사람 손 없이 올라와 **자동 복구를 두 번째로 관찰**했고, **10/19 읽기 확인**(가동 8일 4시간 · 다섯 정상 · healthz 안·밖 200 · 커넥터 1 · 백업·점검 날마다 0 · backups 141 · app.db 그대로 · 보관 37 · TM 10/19 17:56 · 자동 설치 0 유지)을 적었다.
**cloudflared 는 지금 2026.10.0 이다**(10/25 에 `--version` 으로 읽음 · 2026.10.1 권장 경고). 12-19 의 「2026.9.3 → 2026.10.0」 은 그날의 기록이라 그대로 두고 12-25 에서 바로잡았다. 누가 올렸는지는 모른다. 8-8 의 업그레이드 줄은 「2026.10.0 → 2026.10.1」 로 맞췄고 결정(리허설 통과 뒤 따로 · 사본 먼저)은 그대로다.
**cloudflared 프로세스 수는 이 앱 터널(launchd 의 tunnel PID) 하나로만 센다** — 같은 맥에서 mtask 터널도 돈다(12-25).
**정전 뒤 자동 켜짐(전원 뽑기)은 여전히 미확인이고 정식 리허설은 아직이다.** 서버가 읽는 것이 안 바뀌어 재시작은 없었다.
덧붙임(2026-10-25 · 문서 두 줄): 사람이 정해 「부서 리더 계정으로 화면 점검 한 번 더」 를 표에 다시 올렸고(사용자 안내 직전) 12-19 의 판 줄에 「덧붙임 → 12-25」 를 달았다.

**남은 단계는 없다 — 다섯이 다 섰고 5단계도 2026-09-27 판으로 닫혔다.** 다음 판이 이어받는 것은 단계가 아니라 아래 표다. **다만 BK-b 는 열려 있다** — 개발에 API 키가 없어 **캡처 읽기를 실제로 눌러 본 적이 없다.** 사람이 운영에서 한 장 올려 봐야 「모델이 실제 은행 캡처를 얼마나 읽어 내는가」 를 안다.
