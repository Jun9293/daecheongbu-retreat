# 대청부 수련회 시스템 — 미결 목록 (새 채팅이 먼저 읽는다)

갱신: 2026-09-25 **2단계 판 — 업무 추가를 팝업으로** (목업 C).
보드의 「+ 업무 추가」 와 **달력 날짜 칸의 「+」** 가 이제 화면을 옮기지 않고 **팝업**을 연다. 구역은 **새 업무 만들기가 위 · 라이브러리에서 넣기가 아래**이고, 날짜 드롭다운 두 개가 **드로어와 같은 달력 부품**(`DatePick`)으로 바뀌었다 — 안 고르면 「날짜 없음 — 달력 버튼으로 고르기」 다. 저장하면 팝업을 닫고 **그 자리를 다시 그린다**(달력은 보던 달을 안 잃는다).
**엔드포인트 규약은 안 바꿨다** — `/board/add/new` 가 이미 ISO 날짜를 받고 있었고(0단계 훑기), 옛 주소 `/board/add` 는 **같은 몸통을 그린 화면**으로 남는다(시험 둘이 그것을 규약으로 잡고 있고, 자바스크립트가 죽었을 때의 길이다). 몸통은 `partials/addpop.html` **한 벌**이고 팝업은 `/board/add/form` 에서 그것을 받아 간다.
**`originOf` 에 팝업을 등록했다** — 모르면 드로어가 열린 채 팝업을 만지는 순간 드로어가 닫힌다(달력 팝업이 2026-09-24 에 겪은 그 고장). 점검에 갈래 넷(㉒~㉕)을 더했고 **세 화면 · 두 계정**으로 자가시험이 전부 잡았다. **점검은 아무것도 저장하지 않는다**(10장 — 누르면 업무가 생기고 그것은 지울 길이 없다).

**2단계는 닫혔다.** 남은 단계는 3(보드 — 목업 D) · 4(달력 — 목업 E) · 5(마무리)다. 앞 판 보고는 `docs/review/2026-09-25-1단계뒷마무리.md` 로 얼렸다.
