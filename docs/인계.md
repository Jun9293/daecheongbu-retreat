# 대청부 수련회 시스템 — 미결 목록 (새 채팅이 먼저 읽는다)

갱신: 2026-09-25 **2단계 뒷정리 판** — 봐둘것 BJ-c 를 닫았다.
**업무 추가 팝업에서 날짜를 안 골라도 저장된다**(사람이 정함). 안 고르면 **날짜 없는 업무**가 되고 달력이 「날짜가 없는 업무 N건」 으로 따로 모아 둔다(4-13) — 회의 항목 전환이 마감 없는 항목을 넘기는 것과 **같은 함수·같은 규칙**이다(12장). 도메인은 안 건드렸다: 막고 있던 것은 라우터의 파싱 한 줄이었다.
**안 고른 것과 잘못 고른 것을 갈랐다** — 「기간을 다시 골라주세요.」 는 **꼴이 틀린 값**에만, 마감이 시작보다 앞서는 것은 `create_run` 이 자기 말로. 개발 서버에서 실제로 하나 만들어 **달력의 「날짜가 없는 업무」 · 목록의 「날짜 없음」** 까지 확인했다.
**옛 주소 `/board/add` 는 화면으로 남긴다**(사람이 정함 · 시험을 고쳐서까지 지우지 않는다). 링크는 어디에도 없고 주소만 남는다 — **이 줄기는 닫혔다.**
**보드에는 4-1 이 적은 「날짜 없음」 자리가 아직 없다** — 날짜 없는 업무가 개회일 자리에 보통 바로 선다. 봐둘것 **BJ-d** 로 열어 두었고 **3단계(보드)에서 함께** 본다.

**2단계는 닫혔다.** 남은 단계는 3(보드 — 목업 D) · 4(달력 — 목업 E) · 5(마무리)다. 앞 판 보고는 `docs/review/2026-09-25-2단계팝업.md` 로 얼렸다.
