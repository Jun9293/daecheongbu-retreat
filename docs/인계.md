# 대청부 수련회 시스템 — 미결 목록 (새 채팅이 먼저 읽는다)

갱신: 2026-09-26 **4단계 (예산 · 지출 · 달력) — 코드는 닫혔고 화면 점검이 남았다**.
**예산 화면을 시트 모양으로 다시 만들었다** — 구분은 왼쪽 열로 빠져 병합되고, 세부항목이 여럿인 항목은 항목 셀이 병합되며, 구분마다 **소계 줄**이 선다. 「비율」 은 **예산비율**, 옛 「집행률」 칸 자리는 **결산비율**(항목 결산 ÷ **총 결산**)이다 — **다른 수**라 줄마다의 집행률은 화면에서 없어졌다. 고치는 것은 **「전체 편집」 하나**이고 저장은 `POST /budget/bulk` 한 번이다(전부 되거나 전부 안 된다). 줄 끝에 **비고**가 붙었다(`budget_categories.note` · NULL 로).
**지출 화면도 같은 폼·같은 편집 방식이 됐다** — 예산 항목 칸 + 세부항목-2(병합) + 세부항목-3, 「금액」 은 **영수증 금액**, 인원수 칩은 없앴다. 긴 내용(명단 · 비고)은 `…` 로 줄이고 **팝업에서 고쳐 저장**한다. 계좌는 **지출자 이름의 팝업**으로 갔고(목록에 번호가 한 자리도 안 선다), 영수증은 **칩 → 팝업**(보기 · 추가 · 삭제)이다. **규칙은 한 벌이다** — 줄마다 고치기와 묶음 저장이 `한줄을_고친다` 를 같이 지난다.
**식대 인원은 이제 명단 이름 수다**(`domain/meal.인원수`) — 인원 칸을 화면에서 걷었다. 시트에서 들여온 **이름 없는 옛 줄**만 적힌 숫자를 쓴다.
**달력을 목업 E 로 맞췄다** — 범례 · 수련회 음영 · 꼬리표(한 줄) · 일요일·공휴일 붉은 글자 · **공휴일 표**(`app/domain/holidays.py` · 2026~2028) · **한 칸의 업무 전부 보이기**(접기를 걷었다) · 차례는 지연 → 진행중·대기 → 완료 · 지연 칩 앞의 `!` · 끊긴 칩은 **3단계의 `taskpop.js`** 를 「상세 열기」 로 연다 · 터치는 첫 탭 칠함, 두 번째 탭 드로어.
**화면 점검은 못 돌렸다** — 새 갈래를 `docs/checks/*.js` 에 못 심었고 세 화면 × 두 계정 × 두 폭도 안 돌렸다. **막힌 것이 아니라 판이 거기까지 못 간 것**이다(봐둘것 **BJ-i** 에 무엇이 안 재졌는지와 심을 갈래를 적어 두었다). 그 대신 pytest 새 시험 **57개**와 `화면확인용렌더.py` 로 구조를 쟀다 — **그것이 화면 점검을 대신하지 않는다**(10장).
**스스로 정한 자리 다섯**은 보고 6장에 있다 — 그 가운데 둘은 **사람이 한 번 봐 주면 좋다**: 음력 공휴일 값(봐둘것 **BJ-j**)과 「영수증 삭제」 라는 말(하는 일은 떼는 것이다 · 0장).

**남은 단계는 5단계(수입 — 입금 캡처 자동 분류가 걸린 별도 판)다.** 4단계는 코드가 닫혔고 화면 점검이 남았다.
