# 대청부 수련회 시스템 — 미결 목록 (새 채팅이 먼저 읽는다)

갱신: 2026-09-27 **4단계 뒷정리 — 좁은 폭 점검을 관리자 계정으로 돌렸다**.
사람이 창 하나를 **375px** 로 만들어 주어, `phone.js`(목록 · 보드 · 달력)와 `fin.js`(예산 · 지출)를 그 폭에서 돌렸다 — **다섯 화면 전부 빨강 0 · 완주**다(수는 보고 1장). 넓은 폭은 앞 판에서 두 계정으로 이미 돌았으므로, **관리자는 두 폭이 다 찼다.**
**부서 리더 계정의 좁은 폭은 못 돌렸다** — 좁은 창은 관리자 프로필의 것이고, 부서 리더 프로필의 창은 **사람이 다른 일에 쓰고 있는 창과 같은 창**이라 그것을 줄이면 사람 화면이 함께 좁아진다. 「엉뚱한 창을 건드리지 않는다」 가 그 자리다. **막는 자리는 아니다** — 좁은 폭에서 재는 것은 이동 수단과 표 모양이고 계정이 가르는 것은 권한이라, 관리자 판이 그 갈래를 이미 쟀다.
**자료가 없어 못 심는 갈래 둘도 그대로다** — 지연 칩의 `!`(달력 ㉚) · 영수증 없는 줄의 「+ 첨부」(재정 ⑬). 이 회차에 그런 줄이 하나도 없어 고장을 심을 자리가 없고, 점검이 「못 심음」 으로 적는다. **심는 쪽은 앞 판에서 이미 고쳤고** 남은 것은 돌려 볼 자료뿐이다.
**터치 두 단계도 그대로 사람 몫이다** — 넓은 폭은 호버가 있고 좁은 폭은 달력이 주 단위 목록이라, 두 점검 파일 어디에서도 못 잰다. 손가락 달린 기기에서 사람이 본다.
**코드는 한 줄도 안 고쳤다** — 이 판은 돌리고 적기만 했다. pytest · 글검사는 앞 판 값 그대로다(보고 3장).

**남은 단계는 5단계(수입 — 입금 캡처 자동 분류가 걸린 별도 판)다.** 4단계는 코드도 화면 점검도 닫혔다 — **위의 셋(부서 리더 좁은 폭 · 자료 없는 갈래 둘 · 터치)은 4단계를 막는 자리가 아니다.**

**「남은 것」 표에는 다음 판이 이어받아야 할 것만 올린다** (2026-09-24 사람이 정함) —
