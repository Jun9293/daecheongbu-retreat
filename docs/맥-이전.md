# 맥미니 이전 — 2단계 (맥용 실행 파일)

**이 판은 작성과 로컬 검증까지입니다.** 터널 기동 · 실서비스 전환 · push ·
sudo 가 필요한 일은 안 했습니다. 운영의 정본은 아직 `docs/배포-안내.md`
(윈도우)이고, 전환하는 판에서 CLAUDE.md 11장 · 11-2 와 함께 고칩니다.

## 1. 윈도우 쪽에 있던 것 (읽기만 한 점검)

| 무엇 | 어디 | 하는 일 |
|---|---|---|
| `run.bat` | 저장소 뿌리 | 사람이 켜는 창. venv 가 없으면 만들고, `data\app.db` 가 없으면 `seed.py`, 그다음 uvicorn |
| `scripts/serve.bat` | 작업 스케줄러 `대청부 앱` 이 부름 | 창 없이 uvicorn. `data\server.log` 가 5MB 를 넘으면 `.1` 로 밀고 하나만 남김 |
| `scripts/devserve.bat` | 개발 | 포트 8001 · 데이터 폴더를 임시 폴더로 · 실명 게이트(`check_dev_db.py`) 뒤에 `--reload` |
| `scripts/되살아나나.ps1` | 점검(읽기만) | 작업 스케줄러 · 터널 서비스 · 8000 · 백업을 잰다 |
| `scripts/창앞으로.ps1` | 점검 보조 | 화면 점검 창을 앞으로 (서버와 무관) |
| 작업 `대청부 앱` | 작업 스케줄러 | 시작 시 · `serve.bat` · 실패하면 1분 간격 3번 다시 · 배터리 조건 끔 · 제한 없음 |
| 작업 `대청부 백업` | 작업 스케줄러 | 매일 03:00 · `python scripts/backup.py` · 시작 위치 = 저장소 |
| 작업 `대청부 알림` | 작업 스케줄러 | 매일 08:00 · `python scripts/notify.py` · **사용 안 함** 으로 둠 |
| 서비스 `Cloudflared` | 윈도우 서비스 · LocalSystem · 자동 | `cloudflared --config …\systemprofile\.cloudflared\config.yml tunnel run` |
| `config.yml` | `.cloudflared\` | `tunnel` · `credentials-file` · `ingress`(호스트 하나 → `http://127.0.0.1:8000`, 나머지 404) |

작업 스케줄러 등록 내용은 저장소에 파일로 없고 `docs/배포-안내.md` 8-2 · 12-2 에
절차로 있습니다.

## 2. 값 (비밀값 제외)

| 무엇 | 값 |
|---|---|
| 진입 명령 | `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000` |
| 포트 | 운영 8000 · 개발 8001 · **127.0.0.1 에만** 연다 |
| 터널 이름 | `daecheongbu` |
| 호스트명 | `docs/배포-안내.md` 3장의 `ingress` 에 한 곳 (보고에는 안 적습니다 — CLAUDE.md 11-2) |
| 상태 확인 | `GET /healthz` · `GET /login` |

**앱이 읽는 환경변수 이름** (값은 적지 않습니다 — 거의 전부 기본값이 있습니다):

- 경로 · 비밀: `DCB_DATA_DIR` · `DCB_DATABASE_URL` · `DCB_SECRET_KEY` · `DCB_ANTHROPIC_KEY`
- 주소 · 세션: `DCB_BASE_URL` · `DCB_SESSION_COOKIE` · `DCB_PUSH_CONTACT` · `DCB_DEV`
- 상한: `DCB_MAX_ATTACHMENT_MB` · `DCB_MAX_ASSET_MB` · `DCB_TUNNEL_MAX_MB` · `DCB_DISK_FLOOR_MB` · `DCB_DISK_WARN_MB`
- 주기: `DCB_RISK_SCAN_INTERVAL` · `DCB_SUGGEST_QUIET_MIN`
- Claude API: `DCB_ANTHROPIC_URL` · `DCB_LLM_MODEL` · `DCB_LLM_MAX_TOKENS` · `DCB_LLM_TIMEOUT` · `DCB_LLM_PRICE_IN` · `DCB_LLM_PRICE_OUT` · `DCB_USD_KRW`

`DCB_SECRET_KEY` · `DCB_ANTHROPIC_KEY` 는 비워 두면 `data/secret_key.txt` ·
`data/anthropic_key.txt` 를 씁니다(4-12 · 11장) — `.env` 에 적지 않아도 됩니다.
