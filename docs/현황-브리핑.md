## 1. 한 문단 요약

대학청년부 수련회를 준비·진행·정산하는 웹 시스템입니다. 담당 전도사와 총무팀장이 매 회차 바뀌어도
구멍이 생기지 않게 하는 것이 목적입니다. FastAPI + SQLAlchemy + Jinja + SQLite 로 만들었고,
집 윈도우 서버 + Cloudflare Tunnel 로 배포해 링크 하나로 들어옵니다.

**Phase 1**(로그인·권한 / 새 회차 세팅 마법사 / 준비 단계 보드 / 팀별 업무 수집)과
**Phase 2**(진단 패널 / 수련회 진행 화면 / 웹 푸시 / 봉사팀 보기)가 끝났고, 여기에
**달력 보기**를 더했습니다. **Phase 3**(재정·회의록·STT)은 아직입니다.

## 3. 최근에 만든 것 (08-31 ~ 09-01)

### 수련회 진행 `/live` (5장)

**이 화면만 조건이 다릅니다** — 현장에서 휴대폰으로 급히 봅니다.

- 좁은 화면에서는 프로그램 목록과 체크리스트를 **한 번에 하나씩**
- 체크 버튼 44px, 저장 버튼 없이 누르면 바로 반영
- **실패하면 되돌리고 화면에 말합니다** — 현장에서는 콘솔을 아무도 안 봅니다
- `지연`·진행 여부는 저장하지 않고 **시각에서 계산**합니다
- 프로그램표는 지난 회차에서 통째로 복사해 옵니다
- 구간(전/중/후) 안에서 다시 **팀 단위 / 개인 단위**로 가릅니다

### 봉사팀 보기 `/live/staff` (5-8)

원래 쓰던 구글시트의 '봉사자 시간표'를 그대로 옮겼습니다.

- **표를 만드는 곳은 `staff_sheet.build()` 하나**입니다. 화면과 엑셀이 그것을 같이 씁니다 —
  따로 만들면 어긋나는데, 어긋난 쪽이 파일이면 아무도 모른 채 카카오톡으로 돌아다닙니다
- 칸 비율과 글자 크기를 **원본 시트에서 읽은 네 값**에서 함께 끌어옵니다.
  하나만 바꾸면 여백만 넓어집니다
- `ops` 프로그램과 총무팀 개인 항목은 담지 않습니다 — 거르는 것이 이 표의 이유입니다

### 달력 `/calendar` (4-13)

- **마감일에 점 하나.** 기간 띠가 아닙니다 — 15일짜리를 띠로 그리면 달력이 꽉 찹니다
- **마감일이 없는 업무는 달력 아래에 따로** 모읍니다. 조용히 빼면 그게 놓치는 자리입니다
- 점의 색·상태·기한 초과는 **보드의 규칙을 그대로** 씁니다(`bar_style`·`overdue_of`)
- 점을 누르면 `/board?task=` 로 가서 **보드의 상세 패널**이 열립니다. 새로 만들지 않았습니다
- 범위 칩 `내 것`(기본) · `우리 부서` · `전체`. 부서는 **키로 비교**합니다

### 계정과 초대 링크 (4-12)

- 관리자 계정이 넷으로 불어난 것을 정리하고 **재발을 막았습니다** —
  같은 연락처면 새로 만들지 않고 링크만 재발급, 같은 이름이면 멈추고 보여줍니다
- 비활성 계정이 **연락처를 붙들지 않게** 했습니다(`retired_phone`)
- **초대 링크가 완성된 주소로 나옵니다.** 전에는 주소 앞부분을 자리표시자로 찍어서
  사람이 그것을 손으로 갈아 끼우다 토큰까지 건드려 링크가 깨졌습니다.
  `DCB_BASE_URL` 로 정하고, 화면·스크립트가 같은 곳에서 가져옵니다

## 6. 최근에 겪은 함정 (반복하지 않기 위해)

### 서버를 켜 둔 채 코드를 고치면 500 이 납니다

파이썬은 켤 때 읽은 코드를 들고 있는데 화면(템플릿)은 요청마다 디스크에서 다시 읽습니다.
그래서 **새 화면 + 옛 코드**가 짝지어져 터집니다. `/live` 와 `/live/staff` 가 이걸로 세 번 죽었고,
**그때마다 코드는 맞았고 테스트도 통과했습니다.** 지금은 운영에서 템플릿도 켤 때 한 번만 읽습니다.

**화면이 이상하면 먼저 서버를 껐다 켜 보세요.**

### 화면이 그려지는지 보는 시험을 넣었습니다

`test_p30` 이 주요 화면 7개를 실제로 GET 해서 **알맹이까지** 확인하고,
`test_p33` 이 **화면이 읽는 이름을 구조가 다 가졌는지** 대조합니다.
도메인 함수만 시험하면 이 종류의 오류가 안 잡힙니다.

### `.bat` 는 cp949 로 저장합니다

UTF-8 로 두면 한글 주석이 깨져 `set` 줄까지 파싱이 틀어집니다.
실제로 개발 서버가 운영 DB 를 읽은 적이 있습니다.
