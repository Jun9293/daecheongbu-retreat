# 초대 링크와 함께 보낼 안내문 (초안)

총무팀이 카카오톡으로 링크를 보낼 때 **그 앞에 붙이는 글**입니다.
링크만 보내면 받는 사람은 그것이 무엇인지 모르고, 모르는 링크는 안 엽니다.

- **한 사람에게 한 번씩 보냅니다** — 링크는 사람마다 다릅니다. 단체방에
  올리면 먼저 연 사람의 계정으로 다른 사람이 들어갑니다.
- 이름·연락처는 **여기 적지 않습니다.** 이 파일은 공개 저장소에 있습니다 (11-2).
- 아래 `[  ]` 는 보낼 때 채웁니다.

---

## 붙여 쓸 글

```
[이름] 님, 수련회 준비 시스템 링크입니다.

총무팀이 쓰던 노션·구글시트를 한 곳으로 모은 것입니다.
업무 목록과 마감, 회의록, 예산·지출을 여기서 봅니다.

[링크]

· 이 링크는 [이름] 님 것이고 **한 번만 열립니다.** 열면 그 기기에
  로그인 상태가 남아서, 다음부터는 링크 없이 그냥 들어옵니다.
· 다른 분께 넘기지 마세요 — 그분이 [이름] 님으로 들어가게 됩니다.
· 휴대폰에서도 됩니다. 크롬·사파리에서 열고, 홈 화면에 추가해 두면 앱처럼 씁니다.
· 처음 들어가면 볼 곳은 두 군데입니다 —
  **홈**(오늘까지 할 일)과 **수련회 준비 › 목록**(우리 부서 업무).
· 담당자가 비어 있는 업무는 목록에서 「담당자 없음」 을 눌러 정하면 됩니다.
· 링크가 안 열리거나 이미 썼다고 나오면 **총무팀에 말씀해 주세요.**
  새 링크를 다시 보내 드립니다. 계정을 새로 만들지 않으셔도 됩니다.
```

---

## 보내는 사람이 알아 둘 것

- **링크는 발급한 그 자리에서 한 번만 보입니다.** 저장하지 않으므로
  화면을 벗어나면 다시 볼 수 없고, 재발급하면 **앞의 링크는 죽습니다** (4-12).
  그래서 「아까 보낸 링크로 들어가세요」 가 안 됩니다.
- 유효기간은 **7일**입니다. 일주일이 지나면 다시 발급합니다.
- **누구에게 아직 안 보냈는지는 설정 › 사용자 맨 위**에 있습니다.
  「링크 안 받은 사람 N명」 과 「보냈고 아직 안 들어옴 N명」 이 다른 일입니다 —
  앞은 보내는 것이고 뒤는 기다리는 것입니다.
- 링크를 못 받았다는 연락이 오면 **계정을 새로 만들지 말고 재발급**합니다.
  같은 사람의 계정이 둘이 되면 알림이 두 번 가고 담당자 목록에 같은 이름이
  두 번 뜹니다 (4-12).
